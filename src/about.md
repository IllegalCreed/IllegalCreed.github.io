# About IllegalCreed

IllegalCreed is Zhang Xu's personal developer notebook and project index. The
site records a long-term learning roadmap across web engineering, algorithms,
systems, security, DevOps, and software architecture.

The notes are organized as a connected curriculum. They are updated when the
underlying tools or standards change, and link to working projects where a
concept can be explored directly.

## Current projects

- [type-pal](https://pal.illegalscreed.cn/) ([repo](https://github.com/IllegalCreed/type-pal)):
  a from-scratch TypeScript remake of Chinese Paladin (1995), playable in the
  browser, with a visual editor. Unofficial fan project.
- [Algorithm Visualizer](https://algo.illegalscreed.cn/)
  ([repo](https://github.com/IllegalCreed/algorithms-visualization)): 92
  data-structure and algorithm entries
- [LLM Sanguo](https://illegalcreed.github.io/llm-sanguo/)
  ([repo](https://github.com/IllegalCreed/llm-sanguo)): Romance of the Three
  Kingdoms 14 officer stats mapped to an Artificial Analysis model snapshot
- [agent-doc-architecture](https://github.com/IllegalCreed/agent-doc-architecture):
  agent-first documentation for large projects, four posts and a skill
- [skyfire-1943](https://github.com/IllegalCreed/skyfire-1943): an original
  three-view shooter prototype
- [ai-network-guard](https://github.com/IllegalCreed/ai-network-guard): a macOS
  network monitor for overseas AI agents
- [content-studio](https://github.com/IllegalCreed/content-studio): a local-first
  content and video toolkit
- [marketing-ops](https://github.com/IllegalCreed/marketing-ops): a
  credential-isolated multi-channel campaign plugin
- [IllegalCreed Quiz](https://quiz.illegalscreed.cn/) for developer knowledge practice
- [LumiDeck](https://lumideck.illegalscreed.cn/) for browser-based slide
  authoring

Source code and public maintenance history are available through the
[IllegalCreed GitHub profile](https://github.com/IllegalCreed).
