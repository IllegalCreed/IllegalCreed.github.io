# 功能与对比：免费层、DataGrip 与插件

> 基于 TablePlus 5.x · 核于 2026-08

## 速查

- **SQL 编辑器**：语法高亮（按方言）、智能补全（表/列/函数）、SQL 格式化、**代码片段（snippet）**（保存复用常用 SQL）、错误检查、多标签、运行选中/全部、查询历史。轻快但深度功能（执行计划可视化）较弱。
- **数据编辑器**：网格视图、过滤排序、BLOB（图片/文件）预览、外键关联跳转、表单视图（一行一页）。编辑后生成 UPDATE/INSERT/DELETE 可预览。
- **快照（Snapshot）**：**TablePlus 独特功能**——编辑数据前自动创建快照点，误删/误改后一键回滚到快照。这是它区别于 Navicat/DBeaver 的安全亮点。仅 Pro。
- **SSH 隧道（Pro）**：连内网数据库——设 SSH 跳板机，TablePlus 先 SSH 再连内网库，无需额外端口转发工具。免费层不含。
- **多连接多标签**：同时连多个库、开多个标签。免费层有连接数与标签数限制，Pro 无限。
- **查询历史与代码片段**：自动保存查询历史（免费层长度受限）。代码片段保存常用 SQL 复用。
- **数据导出**：CSV、SQL、JSON、Excel（部分格式 Pro）。
- **免费层边界**：连接数（约 2 个）、标签页数、查询历史长度受限；无 SSH 隧道、快照、部分导出格式。轻度日常够用，重度要 Pro。
- **DataGrip 对比**：JetBrains DataGrip 商业订阅、IntelliJ 风格 UI 精致、SQL 重构强（重命名表/列自动改所有引用）、与 IntelliJ 生态（IDEA/PyCharm）集成紧密。TablePlus 更轻量原生、Mac 体验更好。DataGrip 属 JetBrains IDE 生态，本叶对比提及不单独立叶。
- **插件生态**：TablePlus 闭源、原生架构，**无插件生态**——功能固定由厂商决定。这是它区别于 DBeaver（Eclipse OSGi 插件活跃）的劣势。

## 一、SQL 编辑器细节

TablePlus 的 SQL 编辑器轻快，适合日常查询：

```
SQL 编辑器：
┌──────────────────────────────────────────┐
│ -- 查询活跃用户                          │  ← 高亮、补全
│ SELECT id, email, last_login             │
│ FROM users                               │
│ WHERE status = 'active'                  │
│   AND last_login > '2026-08-01'          │
│ ORDER BY last_login DESC;                │
├──────────────────────────────────────────┤
│ [结果网格]                                │
└──────────────────────────────────────────┘
快捷键：⌘+R 运行、⌘+T 新标签、⌘+/ 注释、⌘+⇧+F 格式化
```

### 核心能力

- **语法高亮**：按方言着色关键字、函数、字符串、注释。
- **智能补全**：输入时弹表名、列名、函数、关键字。
- **SQL 格式化**：一键统一缩进与大小写（⌘+⇧+F）。
- **代码片段（Snippet）**：保存常用 SQL（如「查某用户订单」），快捷键插入复用。免费层片段数受限。
- **错误检查**：实时标红语法错误。
- **多标签 + 查询历史**：多 SQL 并行，历史可搜索复用（免费层历史长度受限）。

### 与竞品的差距

- **执行计划可视化弱**：不像 DBeaver/Navicat 那样有 EXPLAIN 树形图形，TablePlus 的执行计划展示较简单——SQL 调优场景略弱。
- **重构弱**：不像 DataGrip 那样能「重命名表/列自动改所有 SQL 引用」。
- **定位取舍**：TablePlus 追求轻快日常查询，不追求 IDE 级 SQL 智能化。

## 二、数据编辑器与快照

### 数据编辑器

- **网格视图**：表数据行列显示，过滤（自定义条件）、排序、分页、列宽。
- **BLOB**：图片字段预览缩略图，文件字段上传下载。
- **外键跳转**：点外键值跳到关联表对应行，快速追溯。
- **表单视图**：一行一页详细查看编辑，适合字段多的表。
- **编辑预览**：编辑后生成 UPDATE/INSERT/DELETE，可预览再提交防误操作。

### 快照（Snapshot）—— 独特安全特性

TablePlus 的快照是它区别于其他客户端的亮点：

```
编辑数据流程：
  1. 你打开 users 表准备编辑
  2. TablePlus 自动创建快照（记录当前状态）
  3. 你误操作：UPDATE users SET email = NULL（全表清空邮箱！）
  4. 发现已晚（提交了）
  5. 一键「恢复到快照」→ 数据回到编辑前状态
```

- **自动快照**：编辑前自动创建，无需手动。
- **回滚**：误改后一键恢复到快照点，避免灾难性数据丢失。
- **Pro 专属**：免费层无快照功能。
- **意义**：数据库编辑最怕误操作（误删、误 UPDATE 全表），快照是安全网。这是 TablePlus 对生产库编辑的安全承诺。

## 三、SSH 隧道与多连接

### SSH 隧道（Pro）

连内网数据库的标准模式：

```
你的电脑 ──SSH──► 跳板机（公网）──► 内网数据库
        TablePlus 自动建立 SSH 隧道

连接配置：
  常规：内网 IP + 端口 + 凭证
  SSH：  跳板机公网 IP + 用户 + 密码/私钥
```

- 先 SSH 到跳板机，再通过隧道连内网库——无需额外端口转发工具。
- Pro 专属，免费层不含。

### 多连接多标签

- 同时连多个数据库（生产、测试、开发）。
- 每个连接开多个查询标签。
- 免费层：连接数（约 2）、标签数受限。Pro：无限。

## 四、免费层 vs Pro 订阅

| 功能 | 免费层（Free） | Pro（月/年/买断） |
| --- | --- | --- |
| 价格 | 免费 | 付费 |
| 连接数 | 限制（约 2） | 无限 |
| 标签页数 | 限制 | 无限 |
| 查询历史长度 | 限制 | 无限 |
| 代码片段数 | 限制 | 无限 |
| SSH 隧道 | ❌ | ✅ |
| 快照（Snapshot） | ❌ | ✅ |
| 部分导出格式 | ❌ | ✅ |
| 主题（深色等） | 基础 | 全部 |

**订阅模式**：

- **月订阅**：灵活，短期项目用。
- **年订阅**：比月划算，长期用户选。
- **买断（Lifetime）**：一次性付费永久用（含当时大版本），适合不想订阅的用户。

**选型**：

- **免费层够**：1-2 个连接、日常简单查询、不需要 SSH 内网、不需要快照。
- **需要 Pro**：多连接、SSH 内网、要快照保安全、要无限标签与历史。

## 五、与 DataGrip 的对比（提及不立叶）

JetBrains 的 **DataGrip** 是 TablePlus 在「现代精致数据库客户端」赛道的有力竞争者。本叶对比中提及，但不单独立叶——DataGrip 属 JetBrains IDE 生态（与 IDEA/PyCharm/WebStorm 同源），是数据库版的 IntelliJ，非独立数据库工具专题。

| 维度 | TablePlus | DataGrip |
| --- | --- | --- |
| 价格 | 免费层 + 付费 | 商业订阅（无免费层） |
| 技术 | 原生（Swift/C#） | Java/IntelliJ 平台 |
| UI 风格 | 原生现代 | IntelliJ 精致 |
| 启动/内存 | 快/轻 | 慢/重（IntelliJ） |
| SQL 重构 | 弱 | **强**（重命名表/列自动改引用） |
| IntelliJ 集成 | 无 | **紧密**（与 IDEA 等共享配置） |
| 跨库 | 约 15+ | 多库（JDBC） |
| 适合 | Mac 原生体验、轻量 | JetBrains 生态用户、SQL 重构 |

**选型**：

- **TablePlus**：Mac 用户、要原生轻量、不在 IntelliJ 生态。
- **DataGrip**：重度用 IDEA/PyCharm、要 SQL 智能重构、不在意 Java 的重。

## 六、插件生态讨论

TablePlus **无插件生态**：

- **闭源**：不像 DBeaver（Apache 2.0 开源），社区无法贡献代码。
- **原生架构**：不像 DBeaver（Eclipse OSGi 插件体系），TablePlus 的原生架构没有标准插件接口。
- **功能固定**：功能路线图由 TablePlus Inc. 决定，用户只能提需求等官方实现。

**对比 DBeaver 的插件生态**：DBeaver 的 Eclipse OSGi 让社区可开发插件（Office 集成、主题、AI 等都有社区或商业插件）。这是 DBeaver 的优势——可扩展。TablePlus 用「原生精致不可扩展」换「轻快」。

**取舍**：

- 要可扩展、跨库多 → DBeaver CE。
- 要原生精致轻快、接受功能固定 → TablePlus。

## 七、定位总结

TablePlus 在数据库客户端赛道的定位：

```
            轻量原生 ←────────────────────→ 功能全深
  TablePlus    ·                                ·    Navicat
  (原生/免费层)                                  (商业/重)
                 DBeaver CE
                 (开源/跨库多/Eclipse 重)
                          DataGrip
                          (订阅/IntelliJ/重构强)
```

- **TablePlus**：原生轻量、现代 UI、Mac 首选、免费层可用。
- **DBeaver CE**：免费开源、跨库最多、插件活跃、Eclipse 重。
- **Navicat**：付费、功能全（同步/备份/建模）、UI 精致但重。
- **DataGrip**：付费订阅、IntelliJ 风格、SQL 重构强、JetBrains 生态。
