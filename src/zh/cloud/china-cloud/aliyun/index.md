# 阿里云

**阿里云**（Alibaba Cloud）是国内**市场份额第一、全球前三**的公有云服务商——它从 2009 年"双 11"锤炼出来的超大规模电商基础设施起步，逐步建成覆盖计算、存储、网络、数据库、AI 的完整产品矩阵。对个人开发者和小团队而言，阿里云的**开发者产品栈**（ECS 虚拟服务器 + RDS 托管数据库 + OSS 对象存储 + CDN + 轻量应用服务器）几乎能拼出一套完整的 Web 应用后端；本站本身就跑在阿里云的 **ECS + RDS** 上。理解阿里云的核心产品选型（什么场景用 ECS、什么场景用轻量、OSS 怎么和 CDN 配合），是国内开发者部署应用的必备技能。

阿里云的开发者考点围绕**"用哪些产品拼出一个 Web 后端"**展开：①**计算层**——ECS（弹性计算，虚拟服务器，灵活但需自管系统）vs 轻量应用服务器（开箱即用、价格低、面向小白）；②**数据库层**——RDS（托管 MySQL/PostgreSQL/SQL Server，自动备份主备）vs PolarDB（自研云原生数据库，存储计算分离、读写分离）；③**存储层**——OSS（对象存储，S3 兼容，放静态资源/图片/备份）；④**加速层**——CDN（内容分发，加速静态资源）与 DCDN（全站加速，动态+静态混合加速）；⑤**Serverless**——函数计算（事件驱动，按调用计费）。本叶聚焦**开发者最常用的产品**，不讲大数据（MaxCompute/DataWorks）、AI（通义/PAI）与企业级中台。

## 评价

**优点**

- **国内生态最全**：ECS/RDS/OSS/CDN/函数计算/PolarDB 一站式覆盖，同账号内产品互通（如 OSS 私有 Bucket 通过 RAM 角色授权给 ECS 访问），免去跨云集成
- **国内访问最优**：节点遍布全国（华北 2 北京、华东 1 杭州、华南 1 深圳等），备案后境内访问延迟低，CDN 加速效果显著
- **文档与社区**：中文文档最完整，开发者社区（云栖、阿里云大学）教程丰富，国内踩坑经验易检索
- **轻量服务器门槛低**：24 元/月即可起步，自带常用应用镜像（WordPress/LNMP/Node.js），个人开发者与小项目零负担上线

**缺点**

- **控制台复杂**：产品线庞大（数百个产品），新手在控制台找功能容易迷路；产品命名混乱（如"云服务器 ECS"和"轻量应用服务器"的区别需仔细辨别）
- **计费项细碎**：按量付费、包年包月、预留实例券、存储容量包、流量包……组合复杂，账单需仔细核算，超量计费容易超支
- **备案强制**：境内服务器（ECS/轻量）必须完成 ICP 备案才能用域名对外提供 80/443 服务，周期 3-22 工作日，是境内上云的硬门槛
- **跨地域费用**：跨地域内网流量（如北京 ECS 访问杭州 OSS）按公网计费，架构设计需注意同地域部署
