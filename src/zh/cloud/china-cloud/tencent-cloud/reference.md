# 参考：腾讯云产品速查与对比

> 基于腾讯云 · 核于 2026-08

## 速查

- **计算两线**：CVM（对标 ECS，灵活生产）vs 轻量应用服务器（开箱即用、个人/小站）。
- **对象存储**：COS，S3 兼容，对标 OSS。
- **数据库**：TDSQL（兼容 MySQL/PG，对标 RDS）；TDSQL-C（云原生，对标 PolarDB）。
- **加速**：CDN，对标阿里 CDN。
- **微信生态**：微信云托管/云开发（腾讯独有，免鉴权调用微信能力）。
- **访问控制**：CAM（对标 RAM）。
- **备案强制**：境内服务器同样必须 ICP 备案。
- **安全铁律**：数据库端口禁公网，SecretId/Key 不写代码。

## 一、开发者核心产品速查（与阿里云对照）

| 阿里云 | 腾讯云 | 对标 AWS | 用途 |
| --- | --- | --- | --- |
| ECS | **CVM** | EC2 | 云服务器 |
| 轻量 | 轻量 | Lightsail | 套餐化虚拟服务器 |
| OSS | **COS** | S3 | 对象存储（S3 兼容） |
| RDS | **TDSQL** | RDS | 托管 MySQL/PG |
| PolarDB | TDSQL-C | Aurora | 云原生数据库 |
| CDN | CDN | CloudFront | 内容分发 |
| RAM | **CAM** | IAM | 访问控制 |
| 函数计算 | 云函数 SCF | Lambda | Serverless 函数 |
| — | **微信云托管/云开发** | — | 微信生态后端（腾讯独有） |

## 二、CVM 实例规格

| 规格 | 比例 | 适合 |
| --- | --- | --- |
| **标准型 S** | 1:4 | 多数 Web 应用（均衡） |
| **计算型 C** | 1:2 | CPU 密集（编译/转码） |
| **内存型 M** | 1:8 | 数据库/缓存 |
| **突发型 T** | 积分制 | 低负载偶发（不适合生产） |

## 三、微信云托管 vs 云开发 vs 传统自建

| 方案 | 后端形态 | 微信鉴权 | 适合 |
| --- | --- | --- | --- |
| **微信云托管** | 容器化 Serverless | 免鉴权 | 有传统后端迁微信生态 |
| **微信云开发** | 云函数+云DB+云存储 | 免鉴权+前端直调 | 小程序快速原型 |
| **传统自建** | CVM 跑后端 | 自己实现 token/签名 | 多端服务/已有设施 |

## 四、安全组端口规范

| 端口 | 协议 | 源 IP | 用途 |
| --- | --- | --- | --- |
| 22 | TCP | 自己 IP/堡垒机 | SSH |
| 80 | TCP | 0.0.0.0/0 | HTTP（备案后） |
| 443 | TCP | 0.0.0.0/0 | HTTPS |
| 3306 | **禁公网** | VPC 网段 | MySQL（仅内网） |
| 6379 | **禁公网** | VPC 网段 | Redis（仅内网） |

## 五、微信开放能力（云托管/云开发可免鉴权调用）

| 能力 | 用途 |
| --- | --- |
| 微信支付 | 小程序内支付 |
| 微信登录 | 获取 openid/unionid |
| 模板/订阅消息 | 推送通知 |
| 客服消息 | 回复客服会话 |
| 内容安全检测 | 检测违规内容 |
| 生成小程序码 | 推广 |

## 六、易错点清单

- **"腾讯云和阿里云产品完全一样"**：片面。核心产品对标，但微信云托管/云开发是腾讯独有，游戏/音视频也是腾讯强项。
- **"云开发适合所有小程序"**：错。云开发有查询数量/执行时长限制，复杂业务或多端服务仍需传统后端或云托管。
- **"微信云托管不用备案"**：不一定。默认域名腾讯统一备案，用自定义域名需自行备案。
- **"SecretId/Key 写代码里方便"**：严重事故。泄漏即全账号沦陷，应用 CAM 实例角色。
- **"数据库端口可以开公网方便远程"**：危险。会被全球扫描爆破，应走内网 + 安全组限源。
- **"云开发没有厂商锁定风险"**：错。云函数/云数据库 API 私有，迁出成本高。
- **"轻量应用服务器适合生产"**：错。套餐化受限，生产用 CVM。
- **"跨地域走内网免费"**：错。跨地域走公网或云联网计费，应同地域部署。

## 七、与阿里云选型建议

| 场景 | 推荐 |
| --- | --- |
| 微信小程序/公众号后端 | **腾讯云**（云托管/云开发免鉴权） |
| 游戏/音视频业务 | **腾讯云**（基础设施强） |
| 已有阿里云账号/技术栈 | 阿里云（迁移成本） |
| 通用 Web 应用 | 二者皆可（按价格/习惯） |
| 大数据/AI/企业中台 | 阿里云（产品更全） |
