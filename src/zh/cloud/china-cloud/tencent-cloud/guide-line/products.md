# 产品：CVM、COS 与 TDSQL

> 基于腾讯云 · 核于 2026-08

## 速查

- **CVM（云服务器）**：腾讯云的虚拟服务器，对标阿里 ECS——规格/镜像/网络/磁盘全可控，但系统运维自己负责。
- **实例规格**：标准型（S，均衡）、计算型（C，CPU 密集）、内存型（M，数据库）、突发型（T，积分制）。
- **镜像**：TencentOS（腾讯自研，免费优化）、CentOS（停维护慎选）、Ubuntu、Windows Server。
- **存储**：系统盘（云硬盘 CBS，高性能云硬盘/增强型 SSD）+ 数据盘。
- **安全组**：CVM 的虚拟防火墙，生产只开 22/80/443，**数据库端口（3306/6379）禁公网**。
- **VPC 与内网**：CVM 放 VPC，与 TDSQL 通过内网通信（免公网费、安全）。
- **COS（对象存储）**：S3 兼容，访问域名 `<bucket>.cos.<region>.myqcloud.com`，静态资源/图片/备份。
- **三种权限**：私有、公共读、公共读写（严禁）。
- **TDSQL**：兼容 MySQL/PG 的托管数据库，主备高可用 + 自动备份 + 按时间点恢复，对标 RDS。
- **CAM（访问控制）**：对标 RAM，CVM 用实例角色访问 COS，不硬编码 SecretId/Key。
- **边界**：Linux 命令归服务器章，本叶只讲腾讯云产品选型。

## 一、CVM：选规格、镜像与存储

CVM（Cloud Virtual Machine）的创建与阿里 ECS 流程一致——选规格、镜像、存储、网络：

- **规格（实例类型）**：命名如 `S5.LARGE8`——S=标准型，5=第 5 代，LARGE8=2 核 8G。四类：①**标准型 S**（CPU:内存约 1:4，多数 Web 应用首选）；②**计算型 C**（1:2，CPU 密集如编译/转码）；③**内存型 M**（1:8，数据库/缓存）；④**突发型 T**（CPU 积分制，便宜但持续高负载限速）。
- **镜像**：①**TencentOS Server**——腾讯自研（基于 RHEL），针对云内核与腾讯云产品优化，免费且官方推荐；②**CentOS**——已停止官方维护，不建议新项目；③**Ubuntu**——社区主流；④**Windows Server**——按许可证贵，.NET 项目用。
- **存储（云硬盘 CBS）**：①**高性能云硬盘**（性价比，多数场景）；②**增强型 SSD 云硬盘**（高 IOPS，数据库）；③**SSD 云硬盘**（上一代）。系统盘 50-100GB 起步；数据单独挂**数据盘**（实例释放时可保留）。
- **网络**：CVM 在某个 **VPC（私有网络）** 的**子网**下，对应一个可用区。建议与 TDSQL 同地域同 VPC，内网互通。

## 二、安全组：CVM 的虚拟防火墙

腾讯云的**安全组**与阿里云功能一致，按入/出方向、协议/端口/源 IP 控制：

| 端口 | 协议 | 源 IP | 用途 |
| --- | --- | --- | --- |
| 22 | TCP | 自己 IP/堡垒机 | SSH |
| 80 | TCP | 0.0.0.0/0 | HTTP（备案后） |
| 443 | TCP | 0.0.0.0/0 | HTTPS |
| 3306 | **禁公网** | VPC 网段 | MySQL（仅内网连 TDSQL） |
| 6379 | **禁公网** | VPC 网段 | Redis（仅内网） |

- **生产铁律**：数据库端口绝不对公网开放，否则被全球扫描爆破；应通过 TDSQL 的内网地址 + 安全组限源 IP 访问。

## 三、COS：S3 兼容的对象存储

**COS（Cloud Object Storage）** 与阿里 OSS 完全对标，S3 兼容：

- **三大概念**：①**存储桶（Bucket）**——顶层命名空间，名字全球唯一；②**对象（Object）**——数据+元数据+Key；③**访问域名**——`<bucket>.cos.<region>.myqcloud.com`（地域级，如广州 `cos.ap-guangzhou.myqcloud.com`）。
- **三种权限**：①**私有**（默认，需签名，敏感数据）；②**公共读**（任何人可读，图片/静态）；③**公共读写**（严禁，会被刷流量）。
- **S3 兼容**：AWS S3 SDK 换 Endpoint（`cos.<region>.myqcloud.com`）+ SecretId/Key 即可访问，与 OSS/S3 无缝切换。
- **典型用法**：静态资源放公共读桶 + 挂 CDN 加速；用户上传头像 → 后端签 URL → 前端直传 COS → 存 Key。
- **CAM 角色授权**：CVM 通过实例角色（CAM）访问 COS，不硬编码 SecretId/Key（与阿里 RAM 角色同理）。

## 四、TDSQL：兼容 MySQL 的托管数据库

**TDSQL** 是腾讯云的托管关系型数据库，对标阿里 RDS：

- **引擎**：兼容 **MySQL / PostgreSQL / MariaDB**。另有 **TDSQL-C**（云原生版本，对标 PolarDB，存储计算分离）。
- **托管能力**：①**主备高可用**（主故障自动切备，SLA 99.99%）；②**自动备份**（每日全量 + 实时 binlog）；③**按时间点恢复**（恢复到过去 5-30 天任意秒）；④**读写分离**（加只读实例分担读压力）。
- **连接方式**：提供内网地址（同 VPC 的 CVM 用，免流量费、延迟低、安全）与外网地址（公网，慎用）。内网域名形如 `gz-cdb-xxx.sql.tencentcdb.com:3306`。
- **安全组/白名单**：TDSQL 默认拒绝所有连接，需在安全组或白名单加 CVM 内网 IP 才能连。

## 五、本类 Web 应用的典型架构（腾讯云版）

与阿里云版架构完全对应，只是产品名换：

```
            用户（境内访问）
                │
                ▼
        CDN（静态资源加速）
         /            \
        ▼              ▼
   COS（图片/静态）  CVM（跑后端进程）
                         │ 内网（VPC）
                         ▼
                   TDSQL MySQL（主备）
                   ├ 自动备份 + binlog
                   └ 按时间点恢复
```

- **选型逻辑**与阿里云一致：CVM 跑后端、COS 放静态、TDSQL 托管库、CDN 加速。
- **何时选腾讯云而非阿里云**：①做微信小程序/公众号后端（微信云托管优势）；②已有腾讯云账号或腾讯系技术栈；③游戏/音视频业务（腾讯基础设施强）。

## 六、计费与省钱

腾讯云计费方式与阿里云一致：

| 计费方式 | 说明 | 适合 |
| --- | --- | --- |
| **包年包月** | 预付月/年，单价最低 | 长期生产 |
| **按量付费** | 按秒计费，随开随关 | 临时测试、压测 |
| **竞价实例** | 竞价空闲资源，可能被回收 | 无状态/可中断任务 |

腾讯云新用户首单常有 1-3 折优惠（与阿里云价格战），轻量服务器 24 元/月起，对个人开发者门槛同样低。
