# 域名解析与境外免备案

> 基于 ICP 备案与域名 · 核于 2026-08

## 速查

- **DNS（域名系统）**：把域名（illegalscreed.cn）翻译成 IP（47.x.x.x），是备案通过后网站能访问的最后一公里。
- **解析服务商**：①阿里云云解析；②腾讯云 DNSPod；③Cloudflare DNS（境外/全球加速）。
- **A 记录**：域名 → IPv4 地址（最常用，指向 ECS 公网 IP）。
- **CNAME 记录**：域名 → 另一域名（常用于 CDN 加速域名指向 CDN 分配的 `xxx.aliyuncs.com`）。
- **AAAA 记录**：域名 → IPv6 地址（IPv6 普及后用，多数站暂不需要）。
- **MX/TXT 记录**：MX 邮件交换（企业邮箱），TXT 文本（域名所有权验证/SPF/DKIM）。
- **TTL（生存时间）**：解析记录的缓存时长，默认 600 秒；改了解析后等 TTL 过期全球 DNS 才重新查询。
- **生效时间**：改解析前调小 TTL（如 60 秒）可加速全球生效；默认 TTL 下，境内数分钟、全球通常 24 小时内生效。
- **境外免备案**：境外服务器（Vercel/Cloudflare/AWS 海外）免 ICP 备案，但境内访问延迟高（跨境/跨海）、可能被干扰。
- **混合策略**：境内备案（低延迟）+ 境外 CDN 边缘（全球加速），大型站才用。
- **本站**：DNS 用阿里云云解析，A 记录指向 ECS 公网 IP，CDN 子域 CNAME 到 CDN 域名。

## 一、DNS 域名解析：备案后的最后一公里

备案通过拿到备案号、云厂商解除 80/443 阻断后，还差最后一步——把域名通过 **DNS** 指向服务器 IP，用户才能用域名访问：

```
用户在浏览器输入 illegalscreed.cn
   → 本地 DNS 缓存未命中
   → 递归查询根 DNS → 顶级域(.cn) DNS → 权威 DNS（云解析/DNSPod）
   → 权威 DNS 返回 A 记录的 IP（47.x.x.x）
   → 浏览器向该 IP 的 443 端口发起 HTTPS 请求
   → ECS/Nginx 响应，返回网站内容
```

- **解析服务商**：域名的**权威 DNS**由谁提供——阿里云云解析、腾讯云 DNSPod、Cloudflare DNS 等。在域名注册商处把**NS 记录**（Name Server）改成解析服务商提供的 NS，DNS 查询才会到该服务商。
- **记录配置位置**：在解析服务商的控制台（如阿里云 DNS 控制台）添加解析记录。

## 二、核心记录类型

| 记录类型 | 含义 | 典型用法 |
| --- | --- | --- |
| **A** | 域名 → IPv4 | `@ → 47.x.x.x`（根域指向 ECS IP） |
| **AAAA** | 域名 → IPv6 | IPv6 站点（多数暂不用） |
| **CNAME** | 域名 → 另一域名 | `cdn → xxx.aliyuncs.com`（CDN 加速域名） |
| **MX** | 邮件交换 | 企业邮箱（如腾讯企业邮） |
| **TXT** | 文本记录 | 域名所有权验证、SPF/DKIM（防垃圾邮件） |
| **NS** | Name Server | 指定权威 DNS 服务商 |

- **A 记录（最常用）**：把根域（`@`，代表 illegalscreed.cn 本身）或子域（如 `api`）指向服务器 IPv4。本站 `@ → ECS 公网 IP`。
- **CNAME（CDN 必用）**：CDN 加速时，CDN 会分配一个域名（如 `xxx.aliyuncs.com`），把自己的子域（如 `cdn.illegalscreed.cn`）CNAME 过去，CDN 接管该子域的流量。
- **www 子域**：通常 `www` CNAME 到 `@`（根域），或直接 A 记录到同一 IP，让 `www.illegalscreed.cn` 与 `illegalscreed.cn` 都能访问。

## 三、解析生效时间与 TTL

- **TTL（Time To Live）**：每条记录的缓存时长（秒）。全球 DNS 服务器在 TTL 内缓存该记录，TTL 过期才重新查询权威 DNS。
- **默认 TTL**：阿里云云解析默认 600 秒（10 分钟）。
- **改解析的技巧**：要改解析（如换服务器 IP）时，**提前把 TTL 调到很小**（如 60 秒），等一个旧 TTL 周期全球缓存过期后，再改记录值，新解析全球快速生效；否则旧 TTL 内部分用户仍访问旧 IP。
- **生效范围**：境内通常数分钟（运营商 DNS 缓存较短），全球通常 24 小时内完全生效。
- **不生效排查**：①NS 是否指向当前解析服务商；②记录是否配置正确；③本地 DNS 缓存（`nslookup`/`dig` 验证）；④TTL 未过期。

## 四、境外服务器：免备案的代价

境外服务器（Vercel/Cloudflare/AWS 海外地域、阿里云海外地域）**免 ICP 备案**，但有代价：

| 维度 | 境内（备案） | 境外（免备案） |
| --- | --- | --- |
| 备案 | 强制 | 免 |
| 境内延迟 | 低（同省<10ms） | 高（跨境跨海，100-300ms+） |
| 境内稳定性 | 稳 | 可能被干扰/限速（跨境链路） |
| 上线速度 | 慢（备案 3-22 工作日） | 快（git push 即上线） |
| DNS | 阿里云云解析/DNSPod | Cloudflare/境外 DNS |
| 适合 | 境内用户为主（本站） | 全球/境外用户、个人/开源项目 |

- **免备案场景**：①开源项目文档（VitePress/Docusaurus 部署 Vercel/Cloudflare Pages）；②个人作品集（追求快速上线，不在意境内延迟）；③面向全球用户的 SaaS。
- **境内备案场景**：①境内用户为主（本站）；②长期合规运营；③追求境内访问体验（CDN 加速效果好）。
- **混合策略**：境内备案服务器（境内低延迟）+ Cloudflare 全球 CDN（境外加速），大型站才用，成本与复杂度高。

## 五、本站 DNS 配置实例

本站（illegalscreed.cn）在阿里云云解析的配置：

| 主机记录 | 记录类型 | 记录值 | TTL | 用途 |
| --- | --- | --- | --- | --- |
| `@` | A | ECS 公网 IP | 600 | 根域名访问 |
| `www` | CNAME | `@` | 600 | www 子域 |
| `cdn` | CNAME | CDN 分配域名 | 600 | 静态资源 CDN 加速 |

- **NS**：在阿里云万网注册域名，NS 默认指向阿里云云解析，无需改。
- **生效**：配置后境内数分钟生效，`nslookup illegalscreed.cn` 返回 ECS IP 即成功。

## 六、备案与 DNS 的顺序

正确的上线顺序：

1. **注册域名**（阿里云万网/DNSPod）。
2. **购买境内服务器**（ECS/轻量）。
3. **提交 ICP 备案**（云厂商控制台，3-22 工作日）。
4. **备案通过拿备案号**，云厂商解除 80/443 阻断。
5. **配置 DNS 解析**（A 记录指向服务器 IP）。
6. **网站可访问**（底部展示备案号 + 工信部链接）。

**注意**：DNS 解析可以在备案期间就配置，但因 80/443 被阻断，备案通过前用域名访问会被云厂商拦截页提示"未备案"。
