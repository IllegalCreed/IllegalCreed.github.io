# 参考：ICP 备案流程与 DNS 速查

> 基于 ICP 备案与域名 · 核于 2026-08

## 速查

- **强制条件**：境内服务器 + 域名 + 80/443 Web 服务 = 必须备案。
- **境外免备案**：境外服务器免备案，但境内访问延迟高。
- **五步流程**：初审 → 短信核验 → 管局终审 → 公安备案 → 完成。
- **周期**：3-22 工作日，管局终审占大头。
- **DNS 核心记录**：A（→IP）、CNAME（→域名）、AAAA（→IPv6）。
- **TTL**：解析缓存时长，默认 600 秒，改前调小加速生效。
- **变更备案**：主体/域名/IP/内容/负责人变更必须做。
- **备案号展示**：网站底部展示，链接工信部查询页。

## 一、备案五步流程速查

| 步骤 | 执行方 | 时长 | 要点 |
| --- | --- | --- | --- |
| ①初审 | 云厂商 | 1-3 工作日 | 资料完整性合规性，被打回重提 |
| ②短信核验 | 工信部→负责人 | 即时（6h 内） | 6 位验证码，超时重发 |
| ③管局终审 | 省通信管理局 | 3-20 工作日 | 人工审核，周期最长一环 |
| ④公安备案 | 公安部平台 | 30 日内提交 | 独立于 ICP，部分省份强制 |
| ⑤备案完成 | — | — | 拿备案号，解除阻断 |

## 二、个人 vs 企业备案资料

| 资料 | 个人 | 企业 |
| --- | --- | --- |
| 身份证件 | ✅ 身份证 | ✅ 法人 + 负责人身份证 |
| 主体证件 | — | ✅ 营业执照 |
| 对公账户验证 | — | ✅（打款验证） |
| 域名证书 | ✅ | ✅ |
| 服务器实例 | ✅ | ✅ |
| 幕布核验/人脸 | ✅ | ✅ |
| 负责人联系方式 | ✅ | ✅ |

## 三、境内 vs 境外服务器对照

| 维度 | 境内（备案） | 境外（免备案） |
| --- | --- | --- |
| 代表 | 阿里云/腾讯云/华为云境内 | Vercel/Cloudflare/AWS 海外 |
| 备案 | 强制 | 免 |
| 境内延迟 | 低（<10ms） | 高（100-300ms+） |
| 上线速度 | 慢（备案 3-22 天） | 快（即时） |
| 适合 | 境内用户（本站） | 全球/开源/个人 |

## 四、DNS 记录类型速查

| 记录 | 含义 | 典型用法 |
| --- | --- | --- |
| **A** | 域名 → IPv4 | 根域指向 ECS IP |
| **AAAA** | 域名 → IPv6 | IPv6 站点 |
| **CNAME** | 域名 → 另一域名 | CDN 加速域名 |
| **MX** | 邮件交换 | 企业邮箱 |
| **TXT** | 文本 | 所有权验证/SPF |
| **NS** | Name Server | 指定权威 DNS |

## 五、备案后维护

| 变更项 | 是否需变更备案 |
| --- | --- |
| 主体（个人改名/企业更名） | ✅ 必须 |
| 域名（加/删） | ✅ 必须 |
| 服务器 IP（换服务器） | ✅ 必须 |
| 网站内容性质（非经营→经营） | ✅ 必须 |
| 负责人 | ✅ 必须 |
| 网站停止运营 | 主动注销 |

## 六、易错点清单

- **"境外服务器也需备案"**：错。境外服务器（Vercel/Cloudflare/AWS 海外）免备案，境内服务器才强制。
- **"备案一次永久有效"**：错。主体/域名/IP/内容/负责人变更必须做变更备案，否则可能被注销。
- **"备案通过就能访问"**：不完整。还需配 DNS 解析（A 记录指向 IP），域名才能真正访问。
- **"个人备案可以卖货"**：错。个人备案不能涉及经营（卖货/广告/收费），经营需企业备案 + ICP 经营许可证。
- **"备案号不展示无所谓"**：错。法规要求网站底部展示备案号 + 工信部链接，缺失会被检查。
- **"改 DNS 解析立即全球生效"**：不一定。受 TTL 影响，改前调小 TTL 加速生效，否则旧 TTL 内部分用户访问旧 IP。
- **"CNAME 和 A 记录一样"**：错。A 指向 IP，CNAME 指向另一域名（CDN 场景必用 CNAME）。
- **"管局终审 1 天就能过"**：不确定。管局 3-20 工作日，各省不同，年底/政策收紧期更慢。
- **"公安备案就是 ICP 备案"**：错。两者独立，ICP 归工信部，公安备案归公安部，拿到 ICP 后 30 日内再做公安备案。
- **"网站停了不用管"**：错。停运应主动注销备案，否则信息残留可能被冒用主体。

## 七、上线顺序速查

```
1.注册域名（万网/DNSPod）
2.购买境内服务器（ECS/轻量）
3.提交 ICP 备案（3-22 工作日）
4.备案通过拿备案号，解除阻断
5.配置 DNS 解析（A 记录→IP）
6.网站可访问（底部展示备案号）
```
