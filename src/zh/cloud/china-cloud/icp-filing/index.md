# ICP 备案与域名

**ICP 备案**（互联网信息服务备案）是中国法规对境内提供互联网信息服务的强制要求——只要你的网站部署在**中国境内的服务器**（阿里云/腾讯云/华为云的境内地域）并对外提供 80/443（HTTP/HTTPS）服务，就**必须**完成 ICP 备案，否则云厂商会阻断访问。这是国内上云区别于海外云（Vercel/AWS/Cloudflare）最特殊的一环，也是**法律强制**的硬门槛——本站（illegalscreed.cn）部署在阿里云境内 ECS，就完成了 ICP 备案。与备案并行的是**域名解析（DNS）**——备案通过后，要把域名通过 DNS（阿里云云解析 / DNSPod）指向服务器 IP，网站才能真正访问。理解备案流程与域名解析，是国内开发者把站点从"本地能跑"推到"线上能访问"的必经之路。

ICP 备案的考点围绕**"境内上云的法律门槛与流程"**展开：①**法律要求**——境内服务器强制备案、境外免备案、备案主体与域名的关系；②**备案流程五步**——初审（云厂商）→ 短信核验 → 管局终审（通信管理局）→ 公安备案 → 备案完成，周期 3-22 工作日；③**域名解析 DNS**——备案通过后用 DNS（阿里云云解析 / DNSPod）把域名指向服务器 IP，含 A 记录、CNAME、解析生效时间；④**备案后维护**——信息变更需做变更备案，否则可能被注销。本叶聚焦**备案机制与域名解析实操**，不讲具体云厂商控制台细节（控制台操作归各云叶）。

## 评价

**优点**

- **合规合法**：备案是国内提供互联网信息服务的法定前置，完成备案才能合法运营，避免被监管处罚或关停
- **境内访问最优**：备案后境内用户访问延迟低（同省 < 10ms），CDN 加速效果显著，是境外云做不到的
- **流程线上化**：阿里云/腾讯云都提供备案小程序/控制台，资料齐全后大部分流程可线上完成，无需线下跑管局
- **域名体系成熟**：阿里云云解析/DNSPod 提供稳定 DNS 解析，配合备案一站搞定

**缺点**

- **周期长**：备案需 3-22 工作日（管局终审占大头），期间网站无法用域名访问，影响上线节奏
- **资料繁琐**：需主体证件、负责人信息、域名证书、服务器实例、幕布拍照核验等，企业备案更复杂
- **维护成本**：备案信息（主体/域名/服务器 IP/网站内容）变更需做变更备案，否则可能被注销
- **境外免备案的诱惑**：海外云（Vercel/Cloudflare）免备案即上线，但境内访问延迟高，需权衡
