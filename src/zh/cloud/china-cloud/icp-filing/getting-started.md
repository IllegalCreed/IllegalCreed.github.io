# 入门：ICP 备案法律要求与域名解析基础

> 基于 ICP 备案与域名 · 核于 2026-08

## 速查

- **ICP 备案定义**：互联网信息服务备案，是中国法规对境内提供互联网信息服务的**强制备案要求**——部署在**中国境内服务器**并对外提供 80/443（HTTP/HTTPS）服务的网站**必须备案**，否则云厂商阻断访问。
- **法律依据**：《互联网信息服务管理办法》《非经营性互联网信息服务备案管理办法》——非经营性网站备案、经营性网站办 ICP 经营许可证。
- **境内强制 vs 境外免备案**：境内服务器（阿里云/腾讯云境内地域）**强制备案**；境外服务器（阿里云海外、Vercel、AWS、Cloudflare）**免备案**，但境内访问延迟高。
- **备案主体**：①**个人备案**（用身份证，网站内容受限，不能涉及经营）；②**企业备案**（用营业执照，可涉及经营，需对公账户验证）。
- **域名要求**：域名需在工信部许可的顶级域（.com/.cn/.net 等通用域），且域名注册满**一定时长**（各省要求不同，通常需注册后才能备案）。
- **备案流程五步**：初审（云厂商）→ 短信核验（负责人手机）→ 管局终审（通信管理局，3-20 工作日）→ 公安备案 → 备案完成。
- **备案周期**：3-22 工作日，管局终审占大头，各省时长不同。
- **DNS 域名解析**：备案通过后，通过 DNS（阿里云云解析 / DNSPod）把域名指向服务器 IP——A 记录（指向 IPv4）、CNAME（指向另一域名）。
- **解析生效时间**：TTL（生存时间）决定，默认 10 分钟，全球生效通常数分钟到 24 小时。
- **本站实践**：illegalscreed.cn 部署在阿里云境内 ECS，已完成个人 ICP 备案，DNS 用阿里云云解析。
- **边界**：本叶讲备案机制与 DNS 实操；具体云厂商控制台步骤归各云叶；DNS 协议原理归网络章。
- **进阶顺序**：[备案流程五步](./guide-line/filing-process) → [域名解析与境外免备案](./guide-line/dns-and-domain) → [参考](./reference)。

## 一、ICP 备案是什么：境内上云的法律门槛

**ICP 备案**（Internet Content Provider 备案）是中国工业和信息化部（工信部）对在中国境内提供互联网信息服务的强制备案制度。法律依据是《互联网信息服务管理办法》（国务院令第 292 号）和《非经营性互联网信息服务备案管理办法》（工信部令第 33 号）：

- **两类 ICP**：①**非经营性 ICP 备案**（简称 ICP 备案）——非经营性网站必须备案，**本站就是这种**；②**经营性 ICP 许可证**——涉及收费/广告等经营性服务的网站需额外办 ICP 经营许可证（门槛更高）。
- **触发条件**：部署在**中国境内服务器**（含阿里云/腾讯云/华为云的境内地域，及境内自建机房）+ 对外提供 80/443（HTTP/HTTPS）Web 服务。
- **不触发的场景**：①境外服务器（免备案）；②仅用 IP 访问不用域名（但实际几乎都要域名）；③只开非 80/443 端口的非 Web 服务（如纯 API 走自定义端口，但实践中不推荐）。

一句话：**境内服务器 + 域名 + Web 服务 = 必须备案**。这是绕不开的硬门槛，本站就备了。

## 二、境内强制 vs 境外免备案

| 维度 | 境内服务器（需备案） | 境外服务器（免备案） |
| --- | --- | --- |
| 代表 | 阿里云/腾讯云/华为云境内地域 | Vercel/Cloudflare/AWS 海外地域 |
| 备案 | **强制**（不备阻断） | **免备案** |
| 境内访问 | 延迟低（同省<10ms），CDN 加速好 | 延迟高（跨海/跨境），可能被干扰 |
| 合规 | 合法运营，受监管保护 | 无需备案，但内容仍受中国法律约束 |
| 上线速度 | 慢（备案 3-22 工作日） | 快（git push 即上线） |

- **境内选备案的理由**：境内用户为主、追求低延迟、长期合规运营（本站选这条）。
- **境外免备案的理由**：个人/全球用户、追求快速上线、不在意境内访问延迟（如开源项目文档站）。
- **混合策略**：境内服务器备案 + 海外 CDN 边缘节点加速全球（成本高，大型站才用）。

## 三、备案主体：个人 vs 企业

备案主体决定了需要什么资料、能做什么内容：

- **个人备案**：用**身份证**备案，网站内容受限——不能涉及经营（卖货/广告/收费）、不能是新闻/论坛/社区等需资质的内容。个人博客/技术站/作品集适合。本站是个人备案。
- **企业备案**：用**营业执照** + 负责人身份证备案，可涉及经营（需配合 ICP 经营许可证），内容范围更广。需对公账户验证主体真实性，资料更繁琐。
- **核验要求**：无论个人企业，负责人都需**幕布拍照核验**（云厂商邮寄专用幕布，背景拍照）或**人脸识别**（部分云支持线上）。

## 四、域名：备案的前提

备案前必须有一个**已注册的域名**，且满足：

- **顶级域许可**：域名需在工信部许可的顶级域列表内（.com/.cn/.net/.org/.net.cn 等通用域，新通用域部分不支持）。
- **注册商**：域名可在任意注册商（阿里云万网/腾讯云 DNSPod/GoDaddy）注册，备案时把域名解析到云厂商的备案体系。
- **注册时长**：部分省份要求域名注册满一定时长（如满 30 天）才能备案，防恶意抢注。
- **域名认证**：域名所有者需与备案主体一致（个人备案域名归个人，企业备案域名归企业）。

## 五、DNS 域名解析：备案通过后的最后一公里

备案通过拿到**备案号**后，还要把域名通过 **DNS（Domain Name System）** 指向服务器 IP，网站才能访问：

- **DNS 的作用**：把人类可读的域名（illegalscreed.cn）翻译成机器可路由的 IP（如 47.x.x.x）。
- **解析服务商**：①**阿里云云解析**（DNS）；②**腾讯云 DNSPod**；③**Cloudflare DNS**（境外/全球）。在域名注册商或解析服务商的控制台配置。
- **核心记录**：①**A 记录**（域名 → IPv4 地址，最常用）；②**AAAA 记录**（→ IPv6）；③**CNAME**（域名 → 另一域名，常用于 CDN 加速域名指向 CDN 分配的域名）。
- **生效时间（TTL）**：每条记录有 TTL（生存时间），默认 600 秒（10 分钟）；改了解析后，等 TTL 过期全球 DNS 服务器才会重新查询，所以改解析前可先把 TTL 调小（如 60 秒）以便快速生效。

## 六、本站实践

本站（illegalscreed.cn）的备案与解析路径：

```
域名 illegalscreed.cn（阿里云万网注册）
   │
   ├─ ICP 备案（个人备案，阿里云控制台提交）
   │    └─ 初审 → 短信核验 → 管局终审 → 公安备案 → 拿到备案号
   │
   └─ DNS 解析（阿里云云解析）
        ├─ @  → A 记录 → ECS 公网 IP（根域名）
        ├─ www → CNAME → @（www 子域）
        └─ cdn → CNAME → CDN 分配域名（静态加速）
```

- **备案号**：在网站底部展示（带工信部链接），是备案完成的标志。
- **解析生效**：备案通过后配 DNS 解析，TTL 10 分钟，境内通常几分钟生效。
