# 入门：华为云产品全景与政企定位

> 基于华为云 · 核于 2026-08

## 速查

- **华为云定位**：国内第三/第四的公有云，背靠华为硬件基因（自研芯片/服务器）与政企客户基础，**政务云、政企转型、国产化替代**领域独特。
- **通用产品对标**：ECS（弹性云服务器，对标阿里 ECS/腾讯 CVM）、OBS（对象存储，对标 OSS/COS）、GaussDB（自研分布式数据库）、CDN。
- **两大差异化**：①**GaussDB**（华为自研分布式数据库，国产化替代 Oracle/MySQL）；②**鲲鹏算力**（基于自研 ARM 芯片鲲鹏的国产化算力底座）。
- **政企基因**：核心客群是政府/金融/能源/大型国企，对合规、自主可控、数据本地化要求高——与阿里/腾讯（互联网起家）不同。
- **ECS（弹性云服务器）**：虚拟服务器，规格/镜像/网络全可控，镜像可选 EulerOS（华为自研）/CentOS/Ubuntu。
- **OBS（对象存储）**：S3 兼容，访问域名 `<bucket>.obs.<region>.myhuaweicloud.com`，与 OSS/COS 对等。
- **GaussDB**：华为自研分布式关系型数据库（兼容 MySQL/PostgreSQL 协议），强调自主可控、国产化替代 Oracle。
- **鲲鹏算力**：基于华为自研 ARM 处理器鲲鹏（Kunpeng）的 ECS 实例，国产化硬件底座，去 Intel 依赖。
- **备案强制**：境内服务器同样必须 ICP 备案（与阿里/腾讯一致）。
- **边界**：本叶只讲通用产品与政企/国产化定位；5G/IoT/汽车等垂直方案不讲；Linux 命令归服务器章。
- **进阶顺序**：[产品：ECS/OBS/GaussDB](./guide-line/products) → [政企定位与鲲鹏](./guide-line/positioning) → [参考](./reference)。

## 一、华为云是什么：政企基因的国产化云

华为云（HUAWEI CLOUD）起源于华为内部的 IT 基础设施（运营商/政企客户服务），2017 年正式强化公有云战略。与阿里云（电商起家）、腾讯云（社交游戏起家）不同，华为云的核心基因是**硬件**（华为是全球领先的通信与服务器硬件厂商，自研芯片/服务器/网络设备）和**政企客户**（政府、金融、能源、运营商、大型国企）。

这决定了华为云的两个核心定位：

- **政务云与政企转型**：政府/金融/国企对合规（等保、涉密）、自主可控（去 IOE、去 Intel）、数据本地化要求极高，华为云通过多项国家认证，是这些行业的首选。
- **国产化替代**：在中美科技脱钩背景下，国产化替代（去 IOE—Oracle/IBM/EMC、去 Intel/Windows）是国家战略，华为云的 GaussDB（自研数据库）和鲲鹏（自研 ARM 算力）是核心载体。

对**互联网/Web 开发者**而言，华为云的通用产品（ECS/OBS/CDN）与阿里/腾讯对等，但开发者生态（文档、社区、SDK 体验）相对弱。选华为云的常见场景是：①政企/政府项目要求；②国产化替代需求；③已有华为硬件/技术栈。

## 二、通用产品：与阿里/腾讯对标

华为云的通用产品命名与阿里/腾讯高度对标：

| 华为云 | 阿里云 | 腾讯云 | 用途 |
| --- | --- | --- | --- |
| **ECS**（弹性云服务器） | ECS | CVM | 云服务器 |
| **OBS**（对象存储） | OSS | COS | 对象存储（S3 兼容） |
| **GaussDB** | PolarDB/RDS | TDSQL/TDSQL-C | 数据库（华为自研） |
| **CDN** | CDN | CDN | 内容分发 |
| **VPC** | VPC | VPC | 私有网络 |
| **IAM** | RAM | CAM | 身份与访问管理 |

- **命名巧合**：华为云和阿里云的虚拟服务器都叫 ECS（弹性云服务器），与腾讯 CVM 不同。
- **OBS S3 兼容**：与 OSS/COS 一样，OBS 兼容 S3 协议，跨云迁移成本低。

## 三、计算层：ECS 与鲲鹏算力

- **ECS（弹性云服务器）**：华为云的虚拟服务器，与阿里 ECS 同名同义——规格（通用计算型/计算加速型/内存优化型）、镜像、网络、磁盘全可控。镜像可选：①**EulerOS（欧拉）**——华为自研 Linux（基于 CentOS），针对华为云优化；②CentOS（停维护）；③Ubuntu；④Windows Server。
- **鲲鹏算力（独特）**：华为云提供基于**自研 ARM 处理器鲲鹏（Kunpeng 920）** 的 ECS 实例（如鲲鹏通用计算增强型），与基于 Intel x86 的实例并列。鲲鹏算力是**国产化硬件底座**，去 Intel 依赖，政府/国企国产化替代项目常用。软件需 ARM 架构适配（多数开源软件已支持 ARM）。

## 四、存储层：OBS

**OBS（Object Storage Service）** 是华为云的对象存储，S3 兼容：

- **访问域名**：`<bucket>.obs.<region>.myhuaweicloud.com`（地域级，如 `obs.cn-north-4.myhuaweicloud.com` 北京四）。
- **三种权限**：私有（默认）、公共读、公共读写（严禁）。
- **S3 兼容**：AWS S3 SDK 换 Endpoint + AK/SK 即可访问，与 OSS/COS/S3 无缝切换。
- **典型用法**：静态资源放公共读桶 + CDN 加速；用户上传签名 URL 直传。

## 五、数据库层：GaussDB（自研差异化）

**GaussDB** 是华为自研的分布式关系型数据库，是华为云相比阿里/腾讯的核心差异化：

- **多模态**：GaussDB 系列——GaussDB(for MySQL)/GaussDB(for PostgreSQL)（兼容协议）、GaussDB 分布式版（自研分布式内核）。
- **国产化替代**：GaussDB 定位是替代 Oracle（政企传统数据库）和国产化 MySQL，强调自主可控（华为自研内核，非基于开源 MySQL 改）。
- **托管能力**：主备高可用、自动备份、读写分离、分布式事务——与 PolarDB/TDSQL-C 对等。
- **政企青睐**：政府/金融（四大行多家用 GaussDB 替代 Oracle）因合规与国产化要求选它。

## 六、加速层 CDN

华为云 CDN 与阿里/腾讯 CDN 功能对等——静态资源缓存到全国边缘节点。华为的全球网络（海外政企客户基础）让华为云 CDN 在海外节点覆盖上有一定优势。

## 七、政企定位与国产化（详见下叶）

华为云的核心差异化在政企与国产化，详见[政企定位与鲲鹏](./guide-line/positioning) 叶：

- **政务云**：政府/金融专属云，通过等保、涉密、可信云认证。
- **国产化替代**：GaussDB 替 Oracle、鲲鹏替 Intel、EulerOS 替 CentOS/Windows，去 IOE 全栈。
- **数据本地化**：数据不出境、本地部署，满足合规。
