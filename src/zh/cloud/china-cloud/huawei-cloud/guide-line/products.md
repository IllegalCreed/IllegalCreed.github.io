# 产品：ECS、OBS 与 GaussDB

> 基于华为云 · 核于 2026-08

## 速查

- **ECS（弹性云服务器）**：华为云虚拟服务器，与阿里 ECS 同名同义——规格/镜像/网络/磁盘全可控，运维自己负责。
- **实例规格**：通用计算型（均衡）、计算加速型（GPU/AI）、内存优化型（数据库）、鲲鹏型（ARM 国产化）。
- **镜像**：**EulerOS（欧拉，华为自研）**、CentOS（停维护）、Ubuntu、Windows Server。
- **鲲鹏 ECS**：基于自研 ARM 芯片鲲鹏 920 的实例，国产化硬件底座，软件需 ARM 适配。
- **存储**：系统盘（云硬盘 EVS）+ 数据盘。
- **安全组**：ECS 虚拟防火墙，生产只开 22/80/443，**数据库端口禁公网**。
- **VPC 与内网**：ECS 放 VPC，与 GaussDB 通过内网通信。
- **OBS（对象存储）**：S3 兼容，访问域名 `<bucket>.obs.<region>.myhuaweicloud.com`，静态资源/图片/备份。
- **GaussDB**：华为自研分布式数据库（兼容 MySQL/PG 协议），国产化替代 Oracle，主备+备份+读写分离。
- **IAM（身份与访问管理）**：对标 RAM/CAM，ECS 用实例委托访问 OBS，不硬编码 AK/SK。
- **边界**：Linux 命令归服务器章，本叶只讲华为云产品选型。

## 一、ECS：选规格、镜像与存储

华为云 ECS（弹性云服务器）的创建与阿里 ECS 流程一致：

- **规格（实例类型）**：①**通用计算型**（CPU:内存约 1:2 或 1:4，多数 Web 应用）；②**计算加速型**（带 GPU/NPU，AI 训练/推理、图形）；③**内存优化型**（1:8，数据库/大数据）；④**鲲鹏通用计算型**（基于 ARM，国产化，见 positioning 叶）。
- **镜像**：①**EulerOS（欧拉）**——华为自研 Linux（基于 CentOS/RHEL），针对华为云与鲲鹏深度优化，免费且官方推荐；②**CentOS**——已停止官方维护，不建议新项目；③**Ubuntu**；④**Windows Server**（按许可证贵，.NET 项目）。2019 年华为把 EulerOS 捐赠给开放原子开源基金会，演化成 openEuler 开源社区。
- **存储（云硬盘 EVS）**：①**通用型 SSD**（性价比，多数场景）；②**超高 IO**（高 IOPS，数据库）；③**极速型 SSD**（最高性能）。系统盘 40-100GB 起步；业务数据挂**数据盘**。
- **网络**：ECS 在某个 **VPC（虚拟私有云）** 的**子网**下，对应一个可用区。建议与 GaussDB 同地域同 VPC 内网互通。

## 二、安全组：ECS 的虚拟防火墙

华为云的**安全组**与阿里/腾讯同理，按入/出方向、协议/端口/源 IP 控制：

| 端口 | 协议 | 源 IP | 用途 |
| --- | --- | --- | --- |
| 22 | TCP | 自己 IP/堡垒机 | SSH |
| 80 | TCP | 0.0.0.0/0 | HTTP（备案后） |
| 443 | TCP | 0.0.0.0/0 | HTTPS |
| 3306 | **禁公网** | VPC 网段 | MySQL（仅内网连 GaussDB） |
| 6379 | **禁公网** | VPC 网段 | Redis（仅内网） |

- **生产铁律**：数据库端口绝不对公网开放，否则被全球扫描爆破；应通过 GaussDB 内网地址 + 安全组限源 IP。

## 三、OBS：S3 兼容的对象存储

**OBS（Object Storage Service）** 与阿里 OSS/腾讯 COS 完全对标，S3 兼容：

- **三大概念**：①**桶（Bucket）**——顶层命名空间，全球唯一；②**对象（Object）**——数据+元数据+Key；③**访问域名**——`<bucket>.obs.<region>.myhuaweicloud.com`（地域级，如 `obs.cn-north-4.myhuaweicloud.com` 北京四）。
- **三种权限**：①**私有**（默认，需签名）；②**公共读**（图片/静态）；③**公共读写**（严禁）。
- **S3 兼容**：AWS S3 SDK 换 Endpoint + AK/SK 即可访问，与 OSS/COS/S3 无缝切换。
- **典型用法**：静态资源公共读桶 + CDN 加速；用户上传头像 → 后端签 URL → 前端直传 OBS → 存 Key。
- **IAM 委托授权**：ECS 通过实例**委托**（IAM agency，对标 RAM/CAM 角色）访问 OBS，不硬编码 AK/SK。

## 四、GaussDB：自研分布式数据库（差异化）

**GaussDB** 是华为云相比阿里/腾讯的核心数据库差异化：

- **产品矩阵**：①**GaussDB(for MySQL)**——兼容 MySQL 协议；②**GaussDB(for PostgreSQL)**——兼容 PG 协议；③**GaussDB 分布式版**——华为自研分布式内核（非基于开源 MySQL 改），支撑海量并发与分布式事务。
- **国产化定位**：GaussDB 的核心卖点是**国产化替代 Oracle**——政企传统用 Oracle，在中美脱钩与国产化战略下，GaussDB 作为华为自研、自主可控的替代方案，被多家银行（四大行）、运营商、政府采用。这与 PolarDB/TDSQL（基于开源 MySQL 内核改）的定位有区别。
- **托管能力**：主备高可用、自动备份、读写分离、按时间点恢复、分布式事务——与 PolarDB/TDSQL-C 对等。
- **连接方式**：内网地址（同 VPC 的 ECS 用，免流量费）+ 外网地址（公网，慎用）。
- **选型**：政务/金融/国企项目要求国产化 → GaussDB；互联网通用业务 → GaussDB 或阿里 RDS/PolarDB 都可（按已有云选）。

## 五、本类 Web 应用的典型架构（华为云版）

与阿里/腾讯版架构对应，只是产品名换：

```
            用户（境内访问）
                │
                ▼
        CDN（静态资源加速）
         /            \
        ▼              ▼
   OBS（图片/静态）  ECS（跑后端进程）
                         │ 内网（VPC）
                         ▼
                   GaussDB（主备）
                   ├ 自动备份 + binlog
                   └ 按时间点恢复
```

- **选型逻辑**与阿里/腾讯一致：ECS 跑后端、OBS 放静态、GaussDB 托管库、CDN 加速。
- **何时选华为云**：①政府/金融/国企政企项目（合规与国产化要求）；②国产化替代需求（去 IOE/去 Intel）；③已有华为硬件/技术栈。互联网通用 Web 开发者通常选阿里/腾讯（生态更丰富）。

## 六、计费

华为云计费方式与阿里/腾讯一致：

| 计费方式 | 说明 | 适合 |
| --- | --- | --- |
| **包年包月** | 预付月/年，单价最低 | 长期生产/政企 |
| **按需** | 按小时计费，随开随关 | 临时测试 |
| **竞价实例** | 竞价空闲资源，可能被回收 | 无状态/可中断 |

政企客户常签年度/多年框架合同，个人开发者用包年包月或按需。
