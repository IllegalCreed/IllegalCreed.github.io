# 关于 IllegalCreed

IllegalCreed 是 Zhang Xu 持续维护的个人技术知识库和项目入口，覆盖 Web 工程、
算法、系统、安全、DevOps 与软件架构。

这里的笔记按学习路径组织，重点记录知识之间的依赖关系，并在工具、标准或实践发生
变化时继续修订。能够通过交互验证的主题，会尽量链接到真实可运行的项目。
