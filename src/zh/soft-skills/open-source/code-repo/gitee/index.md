# Gitee

**国内最大的代码托管与协作平台**——开源中国（OSCHINA）旗下的「中国版 GitHub」，主打**国内访问速度快**这一核心差异化。Gitee 于 2013 年由开源中国推出，服务器位于国内，clone/push/网页访问对国内用户稳定且快，成为 GitHub 在国内不稳定时的主流替代与镜像选择。产品形态对标 GitHub：仓库托管（公开/私有）、Pull Request（PR）协作、Issue 跟踪、**Gitee Pages**（静态站）、**Gitee Go**（流水线 CI/CD）、**Gitee Packages**（制品库）。面向企业，Gitee 推出**企业版**（SaaS 研发协作）与**专业版私有化部署**（私有云/内网），覆盖国内政企、金融、教育等对数据本地化与合规有要求的客户。Gitee 还提供**从 GitHub 一键导入/镜像**的能力，是国内加速 GitHub 仓库的常见手段。需要特别注意的边界：因国内内容合规要求，**Gitee 曾在 2022 年 5 月对公开仓库实行人工审核**（公开库需审核后才能上线），这是它与 GitHub/GitLab 最大的治理差异。本叶讲 **Gitee 平台功能与国内定位**；Git 工具命令用法归版本控制章。

## 评价

**优点**

- **国内访问快**：服务器在国内，clone/push/网页加载稳定高速，是 GitHub 不稳定时的首选替代
- **GitHub 一键导入**：OAuth 授权即可把 GitHub 仓库导入/镜像到 Gitee，做国内加速零成本
- **企业版与私有化**：SaaS 企业版 + 专业版私有化部署，满足数据本地化与合规要求
- **国产化适配**：对接国内身份认证、信创生态，政企/金融/教育场景友好
- **本地化体验**：全中文界面、国内客服、符合国内开发习惯（如微信通知）
- **免费额度够用**：公开/私有仓库免费、5 人团队免费协作
- **Gitee AI**：接开源模型与数据集（模力方舟），提供 AI 队友辅助开发
- **代码克隆检测 CopyCat**：内置代码查重，企业版特色

**缺点**

- **开源生态远弱于 GitHub**：全球开源项目聚集度低，国际化协作天然劣势
- **公开库需内容审核**：2022 年起公开仓库需人工审核才能上线，审核周期影响开源传播（与开源精神冲突，曾引发争议）
- **CI/CD 能力较弱**：Gitee Go 流水线不如 GitHub Actions/GitLab CI 生态丰富、模板多
- **第三方集成少**：Action/插件生态远不及 GitHub Marketplace
- **AI 能力不及 Copilot**：AI 队友体验与生态广度不及 GitHub Copilot
- **私有化部署成本**：专业版私有化需商业授权，社区版能力有限
- **迁移回 GitHub 有成本**：深度用了企业版功能后切换不轻松
- **平台锁定与政策风险**：依赖单一国内平台，政策变动（如审核加严）影响业务
