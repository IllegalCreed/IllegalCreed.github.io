# 参考

> 基于简书官方网站与第三方分析编写 —— 平台事实 / 编辑器 / 专题 / 简书钻 / 衰退数据 / 平台对比 / 时间线

## 关键事实速查

| 项目 | 数值 / 说明 |
|---|---|
| 域名 | jianshu.com |
| 上线时间 | **2013 年** |
| 定位 | **中文综合写作平台**（技术是子集） |
| 母公司 | 独立运营（融资有限） |
| 是否开源 | **否（闭源 SaaS）** |
| 商业模式 | 免费 + 简书钻（弱）+ 广告 |
| 内容形态 | 文章 + 专题（合集） |
| 编辑器 | Markdown + 富文本 |
| 首页流量占比 | **~80%（中心化严重）** |
| 状态 | **近年明显衰退** |
| 中文支持 | 强（纯中文） |

## 编辑器

| 模式 | 特点 |
|---|---|
| Markdown | 程序员友好，代码块、行内代码 |
| 富文本 | 所见即所得 |

### Markdown 元素

| 元素 | 输入 |
|---|---|
| 标题 | `# 标题` |
| 加粗 / 斜体 | `**粗**` / `*斜*` |
| 代码块 | <code>```</code> + 语言 |
| 行内代码 | <code>`code`</code> |
| 引用 | `> 引用` |
| 图片 | 拖拽 / 粘贴上传（**有防盗链**） |
| 表格 | Markdown 表格 |
| 分割线 | `---` |
| 链接 | `[文本](URL)` |

## 专题（合集）

| 类型 | 说明 |
|---|---|
| 官方专题 | 「IT 技术」「读书」「散文」「职场」等，编辑筛选 |
| 个人专题 | 用户自建，聚合自己文章 |
| 投稿专题 | 接受他人投稿，编辑审核 |

### 投稿流程

1. 浏览专题广场
2. 文章发布时投稿到专题
3. 等待编辑审核
4. 通过后获专题页曝光

## 简书钻 / 简书贝

| 项目 | 说明 |
|---|---|
| 简书钻 | 衡量用户「权重」，持有越多点赞权重越大 |
| 简书贝 | 可交易代币（效果有限） |
| 收益分成 | 持有简书钻可获文章收益分成（实际低） |
| 获取 | 写作、点赞、活动奖励 |
| 现状 | 机制效果有限，未能解决核心问题 |

## 衰退关键数据

| 维度 | 表现 |
|---|---|
| 首页流量占比 | **~80%（中心化严重）** |
| 个性化算法 | 几乎无（对比掘金的字节算法） |
| 活跃创作者 | 大量流失到掘金 / 知乎 / CSDN / 公众号 |
| 内容质量 | 整体下滑，注水内容多 |
| 技术内容浓度 | 远低于掘金 / CSDN |
| 商业化 | 简书钻收益低，变现弱 |
| Google / 百度权重 | 下降，搜索流量被分流 |

## 与同类平台对比

| 平台 | 定位 | 资本 | 技术浓度 | 分发 | 状态 |
|---|---|---|---|---|---|
| **简书** | 综合写作 | 独立 | 中（子集） | 首页中心化 | **衰退** |
| 掘金 | 纯技术垂直 | 字节 | 极高 | 个性化推荐 | 增长 |
| 知乎专栏 | 综合问答技术子集 | 知乎 Inc | 中高 | 关注 + 算法 | 稳定 |
| CSDN | 技术博客聚合 | CSDN Inc | 高（搬运） | SEO + 算法 | 稳定 |
| 博客园 | 老牌技术博客 | 独立 | 高（旧） | 几乎无 | 稳定（小众） |
| SegmentFault | 技术问答 + 文章 | 独立 | 中 | 算法 + 问答 | 稳定 |
| 微信公众号 | 私域订阅 | 腾讯 | 中高 | 订阅 + 推荐 | 增长（变现强） |

## 创作者迁移趋势

技术创作者从简书迁移到：

| 目标 | 原因 |
|---|---|
| **掘金** | 字节流量 + 算法推荐 + 技术垂直 |
| 知乎专栏 | 综合流量 + 关注机制 |
| CSDN | SEO 流量稳定 |
| 微信公众号 | 私域流量 + 变现 |
| 个人博客 | 完全自有（Hexo / Hugo / VitePress） |

## 历史文章迁移要点

| 步骤 | 说明 |
|---|---|
| 导出 | Settings → 导出 Markdown 归档 |
| 整理 | 检查格式与图片链接 |
| 图片防盗链 | 简书图片外链 403，需重新上传 |
| 选新平台 | 掘金 / 知乎 / CSDN / 个人博客 |
| canonical | 新平台 frontmatter 设原文 URL |
| 简书原文更新 | 顶部加「本文已迁移至 [新地址]」引流 |

## 重要时间线

| 时间 | 事件 |
|---|---|
| **2013** | **简书上线**，定位「创作社区」 |
| 2014-2015 | 凭简洁 Markdown 编辑器吸引大量创作者 |
| 2015 | 掘金上线（技术垂直竞争者出现） |
| 2017 | 简书钻 / 简书贝代币机制推出 |
| 2018-2019 | 流量与活跃度开始下滑 |
| **2020** | **掘金被字节收购，技术创作者加速流失** |
| 2021-2023 | 简书明显衰退，影响力下降 |
| 2024-2026 | 简书持续运营但边缘化，技术写作首选掘金 |
