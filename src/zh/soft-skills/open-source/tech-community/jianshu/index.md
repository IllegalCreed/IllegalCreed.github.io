# 简书

2013 年上线的**中文综合写作平台**（域名 jianshu.com），早期凭借简洁干净的 Markdown 编辑器与「创作社区」定位，吸引了大量中文创作者——技术写作只是其内容的一个子集，与散文、诗歌、读书笔记、生活随笔并列。简书的核心理念曾是「**慢文字 / 深阅读**」，靠首页推荐与「简书钻 / 简书贝」代币激励创作者。但近年来简书陷入**明显衰退**：首页流量中心化严重（80% 流量集中在首页，缺乏个性化算法）、内容质量整体下滑、商业化变现困难（简书钻等机制效果有限）、优质创作者大量流失到掘金 / 知乎 / CSDN / 微信公众号。技术写作子集在简书上尤为边缘——掘金（字节系，纯技术垂直，算法推荐分发）已基本取代简书成为中文技术内容沉淀的首选。当前简书仍运营，但影响力远不如鼎盛期，更多作为综合长文写作的次要选择存在。

## 评价

**优点**

- **历史积淀**：2013 年上线，早期积累了一批优质中文长文创作者与读者，部分老文章仍有 SEO 长尾流量
- **Markdown 编辑器友好**：对程序员写作友好（早期卖点），代码块、行内代码、富文本切换方便
- **页面简洁**：相比 CSDN / 公众号广告少，阅读体验相对干净
- **综合写作社区**：技术、散文、读书、生活等题材共存，适合不限于技术的写作者
- **门槛低**：注册即写，无审核前置（但有事后审核）
- **专题（合集）**：可投稿到他人或官方的专题合集，获得额外曝光
- **免费**：所有内容开放访问，无付费墙

**缺点**

- **明显衰退**：近年影响力大幅下降，活跃用户与优质创作者流失严重
- **流量分配不公**：首页中心化严重（80% 流量集中），缺乏个性化算法，新人文章曝光难
- **内容质量下滑**：开放免费导致大量低质 / 注水内容，优质内容被淹没
- **商业化失败**：简书钻 / 简书贝等代币机制效果有限，变现能力弱，难以留住优质创作者
- **技术内容边缘化**：技术只是综合写作的子集，浓度远低于掘金 / CSDN，技术读者已迁移
- **审核与限制**：内容审核较严，部分话题受限
- **产品迭代滞后**：相比掘金（字节系）、知乎的产品体验落后
- **SEO 弱化**：Google / 百度对简书的权重在下降，搜索流量被知乎 / CSDN / 掘金分流
