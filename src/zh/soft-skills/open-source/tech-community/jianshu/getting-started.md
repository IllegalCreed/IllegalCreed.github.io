# 入门

> 基于简书官方网站（jianshu.com）与帮助中心编写 —— 注册 / 写文章 / 专题 / 简书钻 / 与掘金对比

## 速查

- 注册：手机号 / 微信 / 微博 / QQ 登录，免费
- 写文章：点击「写文章」，Markdown 编辑器（支持代码块 / 富文本切换）
- 文章结构：标题 / 正文 / 标签（专题）/ 封面
- 专题（合集）：可投稿到他人或官方的专题合集，获额外曝光
- 简书钻 / 简书贝：代币激励机制（效果有限）
- 首页推荐：中心化严重，80% 流量集中首页
- 上线时间：2013 年
- 内容定位：综合写作（技术、散文、读书、生活等子集）
- 状态：近年明显衰退，影响力下降
- 编辑器：Markdown + 富文本，对程序员友好（早期卖点）
- 免费：所有内容开放访问，无付费墙
- 技术写作现状：边缘化，浓度低于掘金 / CSDN

## 简书是什么

简书是一个**中文综合写作平台**，定位与其他平台形成清晰对照：

| 维度 | 简书 | 掘金 | 知乎专栏 | CSDN |
|---|---|---|---|---|
| 定位 | **综合写作社区** | 纯技术垂直 | 综合问答的技术子集 | 技术博客聚合 |
| 上线 | 2013 年 | 2015 年 | 2013 年 | 1999 年 |
| 资本 | 独立（融资有限） | 字节跳动 | 知乎 Inc | CSDN Inc |
| 技术内容占比 | 中等（子集） | **极高** | 中高（子集） | 高（搬运多） |
| 分发 | **首页中心化（衰退）** | 个性化推荐 | 关注 + 算法 | SEO + 算法 |
| 商业化 | 简书钻（弱） | 课程 + 引流 | 盐选会员 | VIP + 广告 |
| 现状趋势 | **衰退** | 增长 | 稳定 | 稳定 |

**核心结论**：简书 = 「**综合写作 + Markdown 友好 + 首页中心化分发**」，曾是优质中文长文社区，但近年明显衰退；技术写作应优先掘金 / 知乎专栏 / CSDN。

## 注册与个人主页

### 注册

访问 [jianshu.com](https://www.jianshu.com)，用手机号 / 微信 / 微博 / QQ 登录。

### 个人主页

- 头像、简介、个人介绍
- 关注 / 粉丝数
- 简书钻持有量
- 文章、专题、收藏
- 写作统计

## 写第一篇文章

点击「写文章」，进入编辑器。

### 编辑器

| 模式 | 特点 |
|---|---|
| Markdown | 程序员友好，支持代码块、行内代码 |
| 富文本 | 所见即所得，适合非技术写作者 |

### 文章结构

| 部分 | 要求 |
|---|---|
| 标题 | 简洁，含关键词 |
| 封面 | 可选，单图或多图 |
| 正文 | Markdown / 富文本 |
| 标签 / 专题 | 投稿到专题合集获曝光 |
| 摘要 | 自动生成或手填 |

### 发布与分发

- 发布后进入「最新」流（时间序）
- 首页推荐**中心化**：编辑人工筛选，流量集中
- 投稿到「专题」获额外曝光（核心分发手段）
- 互动（点赞、评论、收藏）影响推荐

## 专题（合集）

专题是简书的核心分发手段之一。

### 专题类型

| 类型 | 示例 |
|---|---|
| 官方专题 | 「IT 技术」「读书」「散文」等 |
| 个人专题 | 用户自建，聚合自己的文章 |
| 投稿专题 | 接受他人投稿，编辑审核 |

### 投稿流程

1. 在专题广场浏览合适的专题
2. 文章发布时选择「投稿到专题」
3. 等待专题编辑审核
4. 通过后文章显示在专题页，获额外曝光

## 简书钻 / 简书贝

简书曾推出的代币激励机制。

### 机制

- **简书钻**：衡量用户在平台的「权重」，持有越多点赞权重越大
- **简书贝**：可交易的代币（效果有限）
- 持有简书钻可获得文章收益分成（实际收益低）

### 现状

- 代币机制未能解决核心的流量分配与商业化问题
- 变现能力有限，难以留住优质创作者
- 持续运营但热度下降

## 简书的衰退表现

### 流量与活跃度

- 首页流量集中，长尾文章曝光弱
- 活跃用户与优质创作者流失
- Google / 百度搜索权重下降

### 内容质量

- 大量低质 / 注水内容涌入
- 优质内容被淹没
- 技术内容浓度远低于掘金 / CSDN

### 创作者迁移

技术类创作者大量迁移到：

| 目标平台 | 原因 |
|---|---|
| **掘金** | 字节流量 + 算法推荐 + 技术垂直 |
| 知乎专栏 | 综合流量 + 关注机制 |
| CSDN | SEO 流量稳定 |
| 微信公众号 | 私域流量 + 变现 |
