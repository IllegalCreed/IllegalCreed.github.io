# 参考

> 基于 Stack Overflow 官方 Tour / Help Center 与第三方分析编写 —— 平台事实 / 声誉 / 徽章 / 权限 / Collectives / 数据 / 时间线

## 关键事实速查

| 项目 | 数值 / 说明 |
|---|---|
| 创始人 | Jeff Atwood、Joel Spolsky |
| 上线日期 | **2008-09-15** |
| 母公司 | Stack Exchange Inc（Prosus 收购） |
| 收购方 | **Prosus**（2021，18 亿美元） |
| 是否开源 | **否（闭源 SaaS）**，部分工具开源（github.com/StackExchange） |
| 商业模式 | 广告 + Stack Overflow for Teams + 数据授权 |
| 内容形态 | **问答（Q&A）** |
| 标签上限 | 5 个 |
| 每日声誉上限 | +200（被采纳除外） |
| Collectives 推出年 | 2021 |
| Collectives 状态 | **2026 年仍活跃** |
| 改版回滚 | **2026-04-30** 退役 beta 站 |

## 声誉（Reputation）变化

| 行为 | 声誉变化 |
|---|---|
| 注册 | +1 |
| 提问被 up vote | +5 |
| 回答被 up vote | **+10** |
| 回答被采纳 | **+15** |
| 提问 / 回答被 down vote | -2（作者） |
| 你 down vote 他人 | -1（你） |
| 帖子被 spam / offensive flag | -100 |
| 赏金（Bounty）扣分 | -相应数额 |
| 每日上限 | **+200**（被采纳 +15 不计入上限） |

## Collectives™（子社区）

| 项目 | 内容 |
|---|---|
| 推出时间 | 2021 |
| 性质 | 厂商赞助的技术栈子社区 |
| 状态 | **2026 年仍活跃** |
| 已有 Collective | Google Cloud、AWS、Go、Kotlin、Prometheus、GitLab、Wix 等 |
| 角色 | Recognized Member（厂商支持工程师）、Member、Admin |
| 加入 | 在 Collective 页面 Join |
| 价值 | 官方支持工程师直接答疑、专属徽章、推荐流 |

## 提问 close 原因

| 原因 | 含义 |
|---|---|
| Duplicate | 已有相同问题 |
| Needs details or clarity | 信息不足 / 不清晰 |
| Needs more focus | 太宽泛（多个问题） |
| Opinion-based | 观点题（无确定答案） |
| Not reproducible or was caused by a typo | 无法复现或拼写错误 |
| Needs debugging details | 缺调试信息 |
| Not about programming as defined in the help center | 不属于编程范围 |

|---|---|

## 重要时间线

| 时间 | 事件 |
|---|---|
| **2008-09-15** | **Stack Overflow 上线** |
| 2009 | Stack Exchange Network 推出 |
| 2014 | 推出 Stack Overflow for Jobs |
| 2018 | 推出 Stack Overflow for Teams |
| 2020-04 | 流量峰值（疫情） |
| **2021** | **被 Prosus 以 18 亿美元收购**；推出 Collectives |
| 2022-11 | ChatGPT 发布，流量开始下滑 |
| 2023-06 | 版主罢工（70%+ 停工） |
| 2024 | 与 OpenAI / Google 签数据授权；OverflowAI |
| 2024-2025 | 新问题量同比下降 64% |
| 2025-05 | 寻求 rebrand |
| 2026-03 | Redesign beta 发布 |
| **2026-04-13** | DevClass 报道放弃改版 |
| **2026-04-30** | 退役 beta 站，回滚 |
