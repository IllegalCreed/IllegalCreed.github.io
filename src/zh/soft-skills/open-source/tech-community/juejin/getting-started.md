# 入门

> 基于掘金官方帮助中心（juejin.cn）与平台公告编写 —— 注册 / 写文章 / 沸点 / 课程 / 直播 / 掘力值 / 年度榜单

## 速查

- 注册：手机号 / 微信 / QQ / 微博 / GitHub 登录，免费
- 写文章：点击「写文章」，Markdown 编辑器（支持代码块 / 行内代码 / 图片 / 公式）
- 文章结构：封面 / 标签（最多 3 个）/ 分类 / 摘要 / 正文
- 沸点：类 Twitter 的短动态，配话题（#前端 #求职 等）
- 课程：付费 / 免费的视频课程
- 直播：技术分享 / 大会直播（含稀土开发者大会 XDC）
- 掘力值：衡量创作活跃度的指标，决定创作等级
- 创作等级：LV1-LV8，等级解锁权益（如专栏、收益）
- 标签：前端 / 后端 / Android / iOS / 人工智能 / 开发工具 / 阅读 ...
- 推荐流：个性化算法推荐（关注 / 推荐两个 Tab）
- 年度榜单：每年评选「年度影响力创作者」
- 旗下产品：掘金（社区）/ 稀土掘金（旧名）/ 掘金小册（付费专栏）/ 稀土开发者大会（XDC）
- 收购：2020 年被字节跳动收购

## 掘金是什么

掘金是**字节跳动旗下的中文技术内容社区**，定位与其他平台形成清晰对照：

| 维度 | 掘金 | 简书 | 知乎专栏 | CSDN |
|---|---|---|---|---|
| 定位 | **纯技术垂直社区** | 综合写作平台 | 综合问答的技术子集 | 技术博客聚合 |
| 上线 | 2015 年 | 2013 年 | 2013 年 | 1999 年 |
| 资本 | **字节跳动（2020 收购）** | 独立 | 知乎 Inc | CSDN Inc |
| 内容浓度 | **技术极高** | 综合（技术子集） | 中高（技术子集） | 高（但搬运多） |
| 分发 | 个性化推荐 | 首页中心化（衰退） | 关注 + 算法 | SEO + 算法 |
| 编辑器 | Markdown 友好 | Markdown + 富文本 | 富文本 | Markdown |
| 商业化 | 课程 + 引流 | 衰退 | 盐选会员 | VIP + 广告 |

**核心结论**：掘金 = 「**纯技术垂直 + 字节算法分发 + 文章 / 沸点 / 课程 / 直播多元形态**」，是中文技术内容沉淀与个人品牌建设的首选。

## 注册与个人主页

### 注册

访问 [juejin.cn](https://juejin.cn)，用手机号 / 微信 / QQ / 微博 / GitHub 登录。

### 个人主页

- 头像、简介、所在公司 / 职位
- 关注 / 粉丝数
- 掘力值与创作等级
- 文章、沸点、专栏、收藏
- 关联 GitHub

## 写第一篇技术文章

点击右上角「写文章」，进入 Markdown 编辑器。

### 文章结构

| 部分 | 要求 |
|---|---|
| 标题 | 简洁、含关键词（利于推荐与搜索） |
| 封面图 | 可选，但有封面推荐权重高 |
| 摘要 | 一句话概括，进推荐流显示 |
| 分类 | 前端 / 后端 / Android / iOS / 人工智能 / 开发工具 / 阅读 / 职场 / 生活 |
| 标签 | **最多 3 个**，相关且具体 |
| 正文 | Markdown，代码块、行内代码、图片、公式、引用 |

### 编辑器特性

- Markdown 实时预览
- 代码块高亮（指定语言）
- 行内代码 `` `code` ``
- 图片拖拽上传（自动 CDN）
- 数学公式（KaTeX）
- 表格、列表、引用
- 草稿自动保存

### 发布与推荐

- 发布后进「推荐」流（个性化算法按兴趣分发）
- 「关注」流只推送给关注者
- 互动（点赞、评论、收藏、分享）决定推荐权重
- 优质文章可能被官方「精选」

## 沸点（短动态）

类 Twitter 的短内容形态。

### 沸点用途

- 快速分享技术片段 / 工具 / 想法
- 配话题（#前端 #求职 #开源 #daily ...）
- 互动门槛低，适合日常活跃

### 沸点话题广场

访问 [juejin.cn/pin/topics](https://juejin.cn/pin/topics) 浏览话题，参与讨论。

## 课程与直播

### 掘金小册（付费专栏）

- 系统化的技术专栏（如《React 技术揭秘》《Vue.js 源码解析》）
- 付费，作者获分成
- 适合深度体系化内容

### 课程

- 视频 + 文字的系列课程
- 付费 / 免费
- 配套作业与社群

### 直播

- 技术分享 / 大会直播
- 含年度**稀土开发者大会（XDC）**直播

## 掘力值与创作等级

### 掘力值

掘力值衡量创作者在平台上的活跃度：

- 文章质量与数量
- 沸点互动
- 课程贡献
- 持续创作时长

### 创作等级

| 等级 | 大致掘力值 |
|---|---|
| LV1 | 新注册 |
| LV2-LV3 | 入门活跃 |
| LV4-LV5 | 稳定贡献 |
| LV6-LV7 | 资深创作者 |
| LV8 | 头部 KOL |

等级解锁权益：专栏、收益、官方资源扶持、年度榜单资格等。详见 [创作等级升级说明](https://juejin.cn/post/7125658251852513294)。
