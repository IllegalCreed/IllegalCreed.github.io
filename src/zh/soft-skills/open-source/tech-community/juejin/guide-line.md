# 指南

> 基于掘金官方文档与社区运营编写 —— 创作策略 / 标签优化 / 推荐算法 / 课程变现 / 平台对比

## 为什么用掘金：字节算法 + 纯技术垂直

理解掘金的核心——**「字节推荐算法 + 纯技术垂直定位」让它成为中文技术内容分发的最强平台**。

### 中文技术写作者的痛点

| 痛点 | CSDN | 简书 | 知乎专栏 | 博客园 | 掘金 |
|---|---|---|---|---|---|
| 内容浓度 | 高（搬运多） | 低（综合） | 中高（子集） | 高（但旧） | **极高** |
| 分发 | SEO + 算法 | 首页中心化（衰退） | 关注 + 算法 | 几乎无 | **字节算法** |
| 编辑器 | 一般 | 友好 | 富文本 | 一般 | **极友好** |
| 受众 | 全栈 | 泛读者 | 综合 | 老一代 | **新一代** |
| 个人品牌 | 弱 | 弱（衰退） | 中 | 弱 | **强** |

**核心结论**：掘金把「字节推荐算法 + 技术垂直 + 现代 Markdown 编辑器」打包，是中文技术写作者建立个人品牌的首选。

## 创作策略

### 适合掘金的内容

| 内容类型 | 适合度 | 原因 |
|---|---|---|
| 框架 / 库深度教程 | ★★★★★ | 受众精准，推荐强 |
| 源码解析系列 | ★★★★★ | 掘金读者爱深度 |
| 前端 / 大前端实战 | ★★★★★ | 掘金前端用户最多 |
| AI / 大模型应用 | ★★★★★ | 当前热点，流量大 |
| 工程化 / DevOps | ★★★★ | 受众稳定 |
| 求职 / 面试 / 职场 | ★★★★ | 沸点 + 文章双分发 |
| 个人感悟 / 行业观察 | ★★★ | 适度即可 |
| 公司产品软文 | ★ | 易被算法降权 |

### 不适合的内容

- **纯搬运 / 翻译无原创**：会被标记降权
- **离技术太远的内容**：偏离社区定位
- **纯 AI 生成水文**：损害个人品牌
- **过度标题党**：跳出率高反伤推荐

## 标签优化

标签是掘金分发的重要信号（最多 3 个）。

### 标签选择原则

1. **大标签带流量**：前端 / 后端 / Android / iOS / 人工智能
2. **小标签带精准**：React / Vue / Node.js / Go / Python / Rust
3. **细分标签带场景**：Webpack / Vite / 性能优化 / 源码
4. **不堆砌**：3 个标签要相关，无关会被降权

### 典型组合

| 文章类型 | 标签示例 |
|---|---|
| React Hooks 深度 | 前端 / React / JavaScript |
| Vue 3 源码解析 | 前端 / Vue.js / 源码 |
| 大模型 RAG 实战 | 人工智能 / 后端 / Python |
| Go 微服务架构 | 后端 / Go / 微服务 |
| 前端面试总结 | 前端 / 面试 / 职场 |

## 推荐算法与曝光

掘金推荐基于字节系算法，核心信号：

| 信号 | 权重 |
|---|---|
| 点击率（标题 + 封面） | 高 |
| 阅读完成率 | 高 |
| 点赞率 | 高 |
| 评论率 | 中高 |
| 收藏率 | 中高 |
| 分享率 | 中 |
| 关注转化 | 中 |
| 负反馈（举报 / 跳出） | 负 |

### 优化要点

1. **标题与封面**：决定点击率，但避免标题党（跳出反伤）
2. **开头 3 段**：决定留存，用钩子开场
3. **段落短、小标题多**：降低阅读疲劳，提升完成率
4. **代码 + 图解**：技术文章标配
5. **结尾抛问题**：拉评论率
6. **发布时间**：工作日晚 8-10 点、周末下午流量高峰

## 课程与小册变现

掘金提供付费内容形态，是主要变现路径。

### 掘金小册

- 系统化的付费专栏（如《React 技术揭秘》）
- 作者与平台分成（具体比例见协议）
- 适合深度体系化内容（10-30 篇连载）
- 门槛：需达一定创作等级 + 通过审核

### 课程

- 视频 + 文字系列
- 付费 / 免费（引流用）
- 配套作业与社群

### 其他变现

- **引流到自有产品**：课程、SaaS、咨询
- **品牌合作**：头部 KOL 获厂商赞助
- **年度榜单加持**：上榜后商业机会增多

## 字节收购（2020）的影响

2020 年掘金被字节跳动收购后的变化：

### 正面

- **流量加持**：字节系导流（抖音、今日头条技术向）
- **算法升级**：复用字节推荐算法，分发更精准
- **资源投入**：产品迭代加速，XDC 大会规模扩大
- **商业机会**：字节生态合作

### 风险

- **战略依赖**：受字节整体节奏影响
- **审核收紧**：字节系审核标准
- **不确定性**：若字节战略调整，掘金定位可能变化

## 创作策略 Checklist

1. **垂直定位**：聚焦 1-2 个技术栈持续深耕，建立专家形象
2. **标签精准**：3 个标签组合「大 + 小 + 场景」
3. **封面 + 标题**：决定点击率，但避免标题党
4. **深度长文**：掘金读者爱源码解析 / 深度实战
5. **系列连载**：用专栏 / 小册聚合，提升关注转化
6. **沸点活跃**：日常发短动态维持活跃度
7. **课程变现**：达等级后做小册 / 课程获稳定收入
8. **冲击年度榜单**：上榜是强力背书
9. **AI 内容克制**：用 AI 做调研，正文人工写
10. **多平台分发**：掘金 + 知乎 + CSDN + 个人博客同步，吃不同流量
