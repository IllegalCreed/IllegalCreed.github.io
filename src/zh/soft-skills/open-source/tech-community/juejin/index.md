# 掘金

**字节跳动**旗下的**面向全球中文开发者的技术内容分享与交流平台**（全称「稀土掘金」，域名 juejin.cn，2015 年 8 月上线）。掘金定位是「激发开发者创作灵感、激励开发者沉淀分享、陪伴开发者成长」——围绕**技术文章、沸点（短动态）、课程、直播**四大产品形态，配以**掘力值 / 创作等级**成长体系与**年度创作者影响力榜单**激励，并主办年度线下技术大会**稀土开发者大会（XDC）**。2020 年掘金被字节跳动收购，借助字节流量与算法推荐持续增长，已成为中文技术内容沉淀与个人品牌建设的首选平台之一。掘金与简书（综合写作平台，技术只是子集，近年衰退）、知乎专栏（综合问答社区的技术子集）形成对照——掘金是**纯技术垂直**，编辑器对 Markdown / 代码块友好，分发靠个性化推荐算法（非传统首页中心化）。

## 评价

**优点**

- **纯技术垂直**：定位聚焦中文开发者，技术内容浓度高，受众精准，不像简书 / 知乎是综合平台的技术子集
- **字节流量加持**：2020 年被字节跳动收购后，借助字节推荐算法与流量持续增长，分发力强
- **产品形态丰富**：技术文章（长文）+ 沸点（短动态，类 Twitter）+ 课程（付费 / 免费）+ 直播（技术分享 / 大会），覆盖创作 / 学习 / 互动全链路
- **个性化推荐分发**：基于算法按兴趣推荐，避免传统平台（如简书）首页中心化的流量垄断
- **掘力值 / 创作等级**：游戏化激励持续创作，等级解锁权益
- **年度创作者影响力榜单**：每年评选，是中文技术圈认可的荣誉背书
- **Markdown 编辑器友好**：对代码块、行内代码、技术排版优化到位，是中文技术写作体验最好的平台之一
- **稀土开发者大会（XDC）**：年度线下技术大会，集结国内外技术大咖，连接线上社区与线下生态

**缺点**

- **内容注水**：开放免费导致大量低质 / 营销 / 搬运内容，需依赖算法筛选；新人文章曝光难
- **活动营销过度**：签到、抽奖、积分等运营活动有时喧宾夺主，干扰内容消费
- **直接变现有限**：作者主要靠课程分成 / 引流变现，文章本身无类似 Medium Partner Program 的稳定分成
- **AI 内容冲击**：2023 年起 AI 生成内容涌入，质量参差
- **字节系风险**：被字节收购后战略方向、产品迭代受字节整体节奏影响，存在不确定性
- **审核与限制**：内容审核较严，部分敏感技术话题（如翻墙、政治相关）受限
- **国际影响力弱**：几乎纯中文，对英文 / 国际技术圈辐射有限
