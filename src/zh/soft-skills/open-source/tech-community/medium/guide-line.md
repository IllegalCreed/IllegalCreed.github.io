# 指南

> 基于 Medium 官方 Help Center 与平台公告编写 —— 付费墙取舍 / Partner Program 收入优化 / Publication 运营 / Boost 投递 / 平台对比

## 为什么用 Medium：付费墙分成闭环

理解 Medium 的第一性原理——**「会员费池 → 按阅读时长分配给作者」是一个把读者付费直接转成作者收入的闭环**，比广告 / 捐赏 / 自营订阅更省心。

### 传统博客的痛点

自建博客（WordPress / Hexo）的作者要自己解决：托管、CDN、SEO、变现（广告 / 联盟 / 捐赏 / 付费墙插件）。变现链路长且分散，99% 的作者月收入为零。

### Medium 的解法

Medium 把「托管 + 编辑器 + 分发 + 付费墙 + 收款」打包成一个 SaaS：

| 环节 | Medium 提供 | 自建博客 |
|---|---|---|
| 托管 | 内置 | 自己买服务器 |
| 编辑器 | 所见即所得 | 自己选 |
| 分发 | 算法推荐 + 关注 | 纯靠 SEO / 社交分享 |
| 付费墙 | 一键开启 Metered story | 装 Patreon / 会员插件 |
| 收款 | Stripe（Partner Program） | 自己接 Stripe |
| 分成 | 按会员阅读时长 | 自留 100%（但量小） |

**取舍**：用 Medium 等于把「100% 的微小收入」换成「Partner Program 池里按比例分成」，对中长尾作者是净收益，对头部作者（自带流量）则不如 Substack 自营订阅。

## 付费墙取舍：开还是不开

这是 Medium 创作者最重要的决策。

### 开启付费墙（Metered story）

**适合**

- 深度原创观点、行业分析、个人故事
- 目标读者愿意为内容付费（管理者、写作者）
- 你已加入 Partner Program 想获得收入

**不适合**

- 技术 API 文档 / 教程（读者要随时查、复制代码）
- 希望最大化传播与引用的内容
- 引流到自有产品 / 开源项目的布道文

### 付费墙对传播的影响

| 指标 | 开付费墙 | 不开 |
|---|---|---|
| 非会员可读 | 前 3 段 + 每月 3 篇上限 | 全部 |
| 搜索引擎收录 | 收录但用户跳出率高 | 高收录 + 高停留 |
| 社交分享转化 | 低（遇到付费墙会退出） | 高 |
| 直接收入 | 有（Partner Program 分成） | 无 |
| 长尾搜索流量 | 弱 | 强 |

**经验法则**：技术教程类内容**不锁**（吃搜索流量 + 品牌曝光），观点 / 行业分析类内容**锁**（吃 Partner Program 分成）。

## Partner Program 收入优化

收入 = 会员阅读时长 × 互动加权 ×（2026 起）推荐转化奖励。优化方向：

### 1. 提升会员阅读时长

- **标题党要克制**：标题与正文不符会让读者迅速跳出，反而拉低分成
- **开头 3 段决定留存**：用故事 / 反直觉结论 / 数据钩子开场
- **段落短、留白多**：手机阅读体验直接决定完成率
- **配图 + 小标题**：长文每 300 字一个小标题，降低阅读疲劳

### 2. 提升互动

- **结尾抛问题**：评论会显著加权分成
- **引用 + @ 作者**：被引用作者会收到通知，互相导流
- **Series（系列文章）**：读者看完一篇会顺读下一篇，总时长翻倍

### 3. 抓住 2026-02-17 推荐奖励

新规则下，付费墙文章把非会员转化为会员会获额外奖金。优化点：

- 文章深度要足以让读者觉得「值得付费继续读」
- 在付费墙切割点设置悬念（如关键结论 / 数据表放在墙后）
- 配合 Publication 的会员入口引导

### 4. 规避 AI 内容禁令

2024-05 起 AI 生成内容不能进付费墙、不能分成。建议：

- 用 AI 做调研 / 大纲，但正文人工撰写
- 在编辑过程里加入个人案例、独家数据
- 全 AI 文章发到不锁付费墙的开放栏目

## Publication（出版物）运营

Publication 是 Medium 上的「子站点」，适合多人协作或品牌化运营。

### Publication 类型

| 类型 | 示例 | 特点 |
|---|---|---|
| 个人品牌 | 个人作者专栏 | 单作者，多系列 |
| 多人专栏 | *Towards Data Science* | 主题聚合，编辑审核 |
| 公司技术博客 | Stripe / Airbnb engineering | 品牌域名 |
| 开源项目布道 | 框架官方博客 | 文档 + 案例 |

### Publication 角色

| 角色 | 权限 |
|---|---|
| Owner | 全部权限，含删除 |
| Editor | 编辑 / 发布所有文章 |
| Writer | 提交草稿，需 Editor 审核 |
| Draft author | 单次提交草稿 |

### 运营要点

- **编辑审核**：投稿 Publication 等于获得该刊的流量加成，但审核标准高
- **导航与 Series**：把同类文章归入 Series，读者会顺读
- **Logo 与品牌**：统一视觉，便于社媒识别
- **自定义域名**：公司博客强烈建议绑定，保留品牌资产

## Boost 投递技巧

Boost 是 Medium 的算法加权分发，由 100+ 人工提名者评审。

### Boost 评审标准（官方）

- **原创性**：非搬运、非 AI 生成、有独家观点
- **深度与研究**：数据 / 案例 / 引用充分
- **可读性**：结构清晰、排版友好
- **格式规范**：标题与小标题层级正确、图片有 alt

### 如何被 Boost

1. **写深度长文**：2000 字以上、含数据 / 案例
2. **避免常见雷区**：标题党、列表水文、纯 AI 文、搬运
3. **投到 Publication**：很多 Boost 提名人是大型 Publication 的编辑，投稿等于进入他们的视野
4. **关注 Editor Partner Program**：2026 年起编辑对参与文章获分成，会主动打磨你的稿子

### Boost 后效果

被 Boost 的文章通常获得 **10-100 倍** 的曝光提升，是 Partner Program 收入跃升的关键。

## 自定义域名实战

会员可把 Publication 绑定自有域名。

### 配置步骤

1. 购买域名（Cloudflare / Namecheap 等）
2. Publication 设置 → Custom domain → 输入域名
3. 在 DNS 添加 CNAME：`blog` → `medium.com`
4. 等待签发 HTTPS（自动，~10 分钟）

### 注意事项

- 自定义域名**必须随会员**：停缴会员后域名解析失效
- SEO 权重归你的域名，但内容仍托管在 Medium
- 文章 URL 变成 `https://blog.acme.com/your-story-xxx`

## 与其他平台对比

| 需求 | 推荐 |
|---|---|
| 英文长文变现 | **Medium** |
| 开发者技术文章（英文） | dev.to（免费开源） |
| 邮件订阅自营 | Substack |
| 完全自有 + 全控 | WordPress / 自建 |
| 中文技术文章 | 掘金 / 知乎专栏 |
| 中文综合写作 | 简书（衰退中） |

## 创作策略 Checklist

1. **定位**：技术教程不锁付费墙，观点 / 分析类锁
2. **会员**：加入 Partner Program 必须先 $5/月会员
3. **Publication**：长期写作建议建一个，统一品牌
4. **自定义域名**：公司 / 个人品牌强烈建议绑
5. **Boost**：写 2000+ 字深度长文，投 Publication
6. **AI 政策**：AI 仅用于调研，正文人工写
7. **2026-02-17 新规**：付费墙文章设计悬念切割点，抓推荐奖励
8. **多平台分发**：同一篇文章可在 Medium（付费墙）+ dev.to（开放）双发，吃两边流量
