# 参考

> 基于 Medium 官方 Help Center 与平台公告编写 —— 会员 / Partner Program / Publication / Boost / 编辑器 / 分发等级 / AI 政策

## 关键事实速查

| 项目 | 数值 / 说明 |
|---|---|
| 创始人 | Evan Williams（Twitter 联合创始人） |
| 上线时间 | 2012 年 8 月 |
| 现任CEO | Tony Stubblebine（2022-07 起） |
| 运营公司 | A Medium Corporation（私有） |
| 会员价格 | **$5/月** 或 $50/年 |
| 非会员月限 | 3 篇会员文章 |
| Partner Program 加入前提 | 必须先成为付费会员 |
| 收入分配依据 | 会员阅读时长 + 互动加权 |
| 推荐奖励生效日 | **2026-02-17** |
| AI 内容禁令 | 2024-05 起，不得进付费墙 / 不分成 |
| 是否开源 | **否（闭源 SaaS）** |
| 自定义域名 | 会员可用，绑定 Publication |
| 编辑器语言 | 几乎纯英文 |

## 会员（Membership）

| 项目 | 内容 |
|---|---|
| 价格 | $5/月 / $50/年（年付省 ~17%） |
| 权益 | 全部会员文章 + 音频朗读 + 加入 Partner Program 资格 + 自定义域名等 Publication 高级功能 |
| 取消 | Settings → Membership → Cancel，月末生效 |

## Partner Program（合作伙伴计划）

| 项目 | 内容 |
|---|---|
| 加入前提 | 必须是付费会员 |
| 收款 | Stripe（需支持的国家 / 地区） |
| 发薪日 | 每月 8-15 日（发放上月收入） |
| 分成依据 | 会员读者在你文章上的**阅读时长** + 互动加权 |
| 推荐奖励 | **2026-02-17 起**：非会员读完付费墙文章后购买会员，作者获一次性奖金 |
| AI 政策 | 2024-05 起 AI 生成内容不参与分成 |
| 提现门槛 | 无固定门槛，按 Stripe 政策 |

## Publication（出版物）

### 角色

| 角色 | 权限 |
|---|---|
| Owner | 全部权限，含删除 Publication |
| Editor | 编辑 / 发布所有文章 |
| Writer | 提交草稿，需 Editor 审核 |
| Draft author | 单次提交草稿 |

### 自定义域名

| 项目 | 内容 |
|---|---|
| 前提 | 会员 + Publication |
| 配置 | Publication 设置 → Custom domain → 加 CNAME |
| HTTPS | Medium 自动签发 |
| 失效条件 | 停缴会员后域名解析失效 |

## Boost Program（→ Editor Partner Program）

| 项目 | 内容 |
|---|---|
| 评审 | 100+ 名人工 Boost 提名人 |
| 评审标准 | 原创性、深度研究、可读性、格式规范 |
| 流量效果 | 被 Boost 文章曝光提升 10-100 倍 |
| 升级 | 2026 年起 Boost 提名计划 → **Editor Partner Program**（编辑对所有参与文章获分成） |
| 投递技巧 | 写 2000+ 字深度长文、投大型 Publication |

## 分发等级（Distribution）

| 等级 | 流量 |
|---|---|
| Not eligible | 不进入推荐流（违规 / 低质） |
| On platform | 仅关注者可见 |
| Network | 进入主题推荐流 |
| Boosted | 算法加权，大幅推送 |

## 编辑器元素

| 元素 | 输入 |
|---|---|
| 大标题 | `# 标题` |
| 二级标题 | `## 标题` |
| 三级标题 | `### 标题` |
| 加粗 / 斜体 | `**粗**` / `*斜*` |
| 代码块 | <code>```</code> + 语言 |
| 行内代码 | <code>`code`</code> |
| 引用 | `> 引用` |
| 图片 | 拖拽 / 粘贴 |
| 分割线 | `---` |
| 链接 | `[文本](URL)` |
| Series | 发文时勾选 Add to series |

## 文章可见性

| 选项 | 说明 |
|---|---|
| Metered story（付费墙） | 非会员限读，参与 Partner Program 分成 |
| Public | 全部可读，不分成 |
| Unlisted | 仅链接可访问，不进推荐流 |

## AI 内容政策（2024-05 起）

| 政策 | 说明 |
|---|---|
| 付费墙 | AI 生成内容**不得**设为付费墙文章 |
| Partner Program | AI 文章**不参与**分成 |
| 标注 | 重度 AI 辅助文章建议在文中标注 |
| 工具型 AI | 用 AI 做调研 / 大纲允许，但正文需人工撰写 |
