# 隐私政策

最近更新：2026 年 7 月 27 日

本政策适用于个人网站 `illegalscreed.cn` 和算法可视化站
`algo.illegalscreed.cn`。

## 处理的信息

个人网站使用 Google Analytics 了解汇总访问情况和页面性能。Google Analytics
可能根据 Google 的政策处理页面 URL、浏览器和设备特征、大致位置、来源页面和交互
信息，并使用 Cookie 或类似标识符。

算法可视化站已准备接入 Google AdSense。广告审核通过并启用后，Google 及其广告
合作伙伴可能使用 Cookie 或类似标识符投放、衡量和保护广告。个人主页本身不加载
AdSense 广告脚本。

Web 服务器可能为安全和运行故障排查临时处理标准请求日志，包括 IP 地址、User-Agent、
请求路径、响应状态和时间。这两个站点当前不提供账号注册或评论功能。算法可视化站
不使用自定义行为分析，也不会发送搜索、播放、输入、测验或分享事件。

## 广告选择与同意

你可以在 [Google 广告设置](https://adssettings.google.com/)中查看或修改广告
个性化设置，也可以安装
[Google Analytics 停用浏览器插件](https://tools.google.com/dlpage/gaoptout)。

在欧洲经济区、英国、瑞士等依法需要同意的地区启用个性化广告前，站点会通过
AdSense 的“隐私权和消息”使用 Google 认证的同意管理平台。

## 外部服务

项目链接可能跳转到 GitHub 或其他独立运营的网站。离开本域名后，应以对应网站的
隐私政策为准。
